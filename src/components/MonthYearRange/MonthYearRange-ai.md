# MonthYearRange

## Назначение

Управляемый диапазон месяцев с двумя полями «от» / «до» и кнопками сдвига обеих границ назад и вперёд. Поля и кнопки предоставляет потребитель через render-props; компонент задаёт раскладку, согласует выбранные границы и выполняет арифметику дат.

Используй когда: нужно выбрать период с точностью до месяца и перелистывать его на месяц, квартал или год.

Не используй когда: нужен диапазон полных дат с выбором дня — `DateRange`; нужен один месяц — `MonthYearField` или `ChipMonthYearPicker`; нужна только сетка календаря — `Calendar`.

---

## Варианты и props

`IMonthYearRangeProps` наследует HTML-атрибуты `div` без `defaultValue` и стандартного `onChange`. Состояние диапазона хранит потребитель: компонент вызывает `onChange`, а новые значения получает через `value`.

### Обязательные props

| Prop | Тип | Описание |
|---|---|---|
| `value` | `TMonthYearRangeValue` | Кортеж `[start, end]` в формате `format` (по умолчанию `YYYYMMDD`). Пустая строка означает невыбранную границу. |
| `onChange` | Callback | Получает обе границы при изменении любого поля или сдвиге диапазона. |
| `renderPickerFrom` | Render-prop | Поле выбора месяца «от». |
| `renderPickerTo` | Render-prop | Поле выбора месяца «до». |
| `renderButtonBack` | Render-prop | Кнопка сдвига назад. Обязателен по типу даже при `hideNavigation`. |
| `renderButtonForward` | Render-prop | Кнопка сдвига вперёд. Обязателен по типу даже при `hideNavigation`. |

### Опциональные props

| Prop | По умолчанию | Описание |
|---|---|---|
| `format` | `dateFormatYYYYMMDD` | Формат дат moment в `value` и в `onChange` пикеров. Передаётся пикерам в render-props вместе с `value` и `onChange`. |
| `shiftAmount` | `1` | Величина сдвига обеих границ в единицах `shiftUnit`. |
| `shiftUnit` | `EMonthYearRangeShiftUnit.MONTH` | `MONTH`, `QUARTER` или `YEAR`: значения enum — строки `month`, `quarter`, `year` для Moment. |
| `hideNavigation` | `false` | Скрывает обе кнопки: их render-props не вызываются. |
| `className` | — | Дополнительный класс корневого контейнера, объединяется с внутренним через `clsx`. |

### Значение и согласование границ

Формат дат задаёт `format`, по умолчанию — `dateFormatYYYYMMDD` из `src/consts/DateConst.ts`. Хотя поля выбирают месяц, компонент хранит полную дату и не приводит день к первому числу месяца. Допускается неполный диапазон: `["", end]`, `[start, ""]` или `["", ""]`.

Обработчики полей сравнивают даты хронологически через `isDateAfter` в `utils.ts`: обе строго парсятся `moment(value, format, true)`, сравнение строк не используется.

- новая граница «от» больше непустой «до» → `onChange([date, ""])`;
- новая граница «до» меньше непустой «от» → `onChange(["", date])`;
- равные границы сохраняются; если новая или противоположная граница пустая, порядок не проверяется.

Если хотя бы одна из сравниваемых дат невалидна в `format`, порядок считается корректным и значение записывается как есть: компонент не валидирует строку пикера в обработчике поля. Потребитель отвечает за формат и исходный порядок `value`.

### Что получают render-props

| Поле | Кому передаётся | Контракт |
|---|---|---|
| `value` | Пикерам | Соответствующая строка `start` или `end`. |
| `format` | Пикерам | Значение `format` компонента. При spread в `MonthYearField` задаёт полю тот же формат. |
| `onChange` | Пикерам | Принимает новую строку и согласует границы по правилам выше. |
| `children` | Кнопкам | Иконка направления: `CaretleftStrokeSrvIcon20` / `CaretrightStrokeSrvIcon20` с `paletteIndex={5}`. |
| `className` | Кнопкам | Класс `monthYearRangeButton` из LESS-модуля; отдельный класс `disabled` не добавляется. |
| `disabled` | Кнопкам | `true`, если хотя бы одна граница пустая. Применить его к DOM-кнопке обязан потребитель. |
| `onClick` | Кнопкам | Обработчик сдвига; при неполном или невалидном диапазоне не вызывает `onChange`. |

В примерах объект пикера целиком передаётся в `MonthYearField`, объект кнопки — в `ButtonIcon`. Собственных props `size`, `status` или `limitRange` у диапазона нет: их настраивают на полях. `format` задаётся на MonthYearRange и приходит в объект пикера. Не задавай `format` полю отдельно: если он стоит в JSX до spread, его перезапишет формат диапазона; если после — формат поля и диапазона разойдутся.

### Сдвиг диапазона

- Сдвиг (`shiftMonthYearRange` в `utils.ts`) строго парсит обе границы через `moment(value, format, true)`. Если хотя бы одна невалидна, функция возвращает `null` и `onChange` не вызывается.
- Кнопка назад сдвигает границы на `-shiftAmount`, вперёд — на `shiftAmount` через `Moment.add`. Обе границы сдвигаются независимо на одну величину; день сохраняется или сокращается до последнего дня целевого месяца. Например, `20240331` минус месяц → `20240229`, `20240229` плюс год → `20250228`.
- `shiftAmount` передаётся в Moment без проверки: рассчитан на целые положительные значения, отрицательное меняет направление кнопок.
- Сдвиг не исправляет порядок входного кортежа и не проверяет ограничения календаря `limitRange`. Потребитель согласует их с полями самостоятельно.
- Результат сериализуется обратно в `format`. Сдвиг на месяц, квартал или год может изменить длину диапазона в днях.

### Корневой элемент

`ref` указывает на корневой `div`. Остальные HTML-атрибуты (`id`, `data-*`, `aria-*`, `style`, обработчики событий) передаются на этот же элемент. `children` допускается унаследованным типом, но содержимое контейнера задаётся render-props и иконкой-разделителем.

## Инварианты

- `forwardRef` обязателен; корневой DOM-элемент и ref-target — `HTMLDivElement`.
- Публичные имена `MonthYearRange`, `IMonthYearRangeProps`, `IMonthYearRangeButtonProvideProps`, `IMonthYearRangePickerProvideProps`, `TMonthYearRangeValue` и `EMonthYearRangeShiftUnit` экспортируются через `src/components/MonthYearRange/index.ts`; интерфейсы и `TMonthYearRangeValue` живут в `types.ts`, компонент — в `MonthYearRange.tsx`, enum — в `enums.ts`. Имена, типы и enum-значения нельзя менять без согласования. `utils.ts` внутренний и в barrel не экспортируется.
- Формат по умолчанию `YYYYMMDD` и пустая строка как невыбранная граница — часть контракта. `value` и аргумент `onChange` пикера должны быть в формате `format`.
- `disabled` кнопок зависит только от пустых границ; невалидные даты блокирует сам обработчик сдвига.
- Порядок содержимого: кнопка назад → поле «от» → иконка-разделитель → поле «до» → кнопка вперёд. `hideNavigation` исключает вызовы обоих render-props кнопок.
- `displayName` — `"MonthYearRange"`; React 17-совместимость сохраняется, React 18-only API не добавлять.
- Story IDs `components-date-components-monthyearrange--*` связаны с baseline `__screenshots__/date-components-monthyearrange--{story}--{xs|xl}.png`: test-runner удаляет префикс `components-` из имени файла. Не переименовывать stories без обновления скриншот-тестов.

## Accessibility

- Корневой `div` — контейнер без собственной роли, фокус-менеджмента или клавиатурной навигации. Переданные `aria-*` относятся к нему.
- Доступные имена полей «от» / «до» и кнопок с иконками задаёт потребитель. В `renderButtonBack` / `renderButtonForward` следует передать локализованные `aria-label` или `title`; компонент текста не добавляет.
- Переданный render-prop `disabled` нужно применить к нативной кнопке. Даже если потребитель его проигнорирует, обработчик дополнительно блокирует сдвиг неполного диапазона.
- Поведение полей, календаря, сообщения об ошибке и порядок табуляции определяются возвращёнными компонентами. Собственного `aria-live` и автоматического объявления изменённого диапазона нет.

## Связанные компоненты

- `DateRange` — альтернатива для диапазона полных дат. Имеет похожий render-prop API и дополнительные единицы сдвига `DAY` / `WEEK`; валидность дат перед сдвигом проверяет так же.
- `MonthYearField` — поле выбора одного месяца, используемое в примерах для обеих границ. Компонент диапазона не импортирует его напрямую.
- `ButtonIcon` — кнопка для переданных иконки, класса, `disabled` и `onClick` в примерах; доступное имя добавляет потребитель.

В `related` включён `DateRange` как альтернатива. Поля и кнопки выбирает потребитель, прямой зависимости по рендеру или наследования их интерфейсов в MonthYearRange нет.
