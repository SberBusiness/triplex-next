<Title>v1.57.0</Title>

<Heading>Изменения</Heading>

**Button**

- В режиме `loading` заблокирована повторная активация кнопки по Enter и пробелу.

**DatePickerExtended**

- В мобильной шторке фокус ведёт себя как в десктопном календаре: при открытии с клавиатуры переходит в шторку и после закрытия возвращается на поле, при открытии тапом остаётся на месте. Касается `DateField`, `MonthYearField`, `ChipDatePicker`, `ChipMonthYearPicker`.

**DropdownDesktop**

- Проведён AI-рефакторинг.
- Исправлено: внешний `ref` больше не вызывается повторно на каждом рендере.
- Оптимизировано: прокрутка и изменение размеров окна не вызывают лишних рендеров, пока положение меню не изменилось; перерасчёт позиции откладывается, предыдущий запланированный вызов отменяется.
- Исправлено: закрытие одного из нескольких открытых меню больше не снимает блокировку клавиш прокрутки у остальных.

**FormFieldClear**

- Проведён AI-рефакторинг.

**FormFieldCounter / FormFieldDescription**

- Рефакторинг без изменений API. Раскладка описания со счётчиком включается до первой отрисовки, без кратковременного мигания.

**LightBox**

- При ширине окна до 767px включительно у `LightBox.Controls` добавлен нижний отступ 8px.

**ModalWindow**

- Вертикальная полоса прокрутки в `ModalWindow` теперь отображается только при переполнении содержимого.

**MultiselectField**

- Если в `pullerProps` передан свой `children`, шторка удерживает фокус внутри и после открытия мышью или тапом не возвращает его в поле. В остальных случаях поведение фокуса не изменилось.

**OverlayBase**

- Флаги `opening` и `closing` приходят в `children` в том же рендере, что и новое значение `opened`. Раньше один рендер они оставались прежними.

**Puller**

- Шторка теперь удерживает фокус внутри. Добавлено свойство `focusTrapProps` для настройки ловушки фокуса, отключается через `{ active: false }`. При открытии фокус ставится на саму шторку, а не на первый интерактивный элемент; элемент, уже получивший фокус внутри шторки (например, поле с `autoFocus`), сохраняет его.
- Шторка закрывается по `Escape`, когда фокус внутри неё. Внешняя шторка или модальное окно при этом не закрываются.
- Во время анимации закрытия шторка больше не перехватывает клики и тапы: они сразу доходят до страницы.
- Содержимое шторки больше не монтируется заново в начале закрытия: состояние дочерних компонентов сохраняется, `autoFocus` повторно не срабатывает.
- Добавлена клавиатурная навигация по `PullerList` внутри `DropdownListContext.Provider` со значением из `useDropdownListKeyboard`: стрелки перемещают активный элемент, `Enter` и пробел выбирают его. Добавлено свойство `PullerListItem.keyCodesForSelection`.

**Suggest**

- В мобильной шторке активная опция выбирается с клавиатуры только по `Enter`: пробел в поле ввода остаётся вводом.

**SuggestField**

- При закрытии мобильной шторки фокус возвращается в поле, шторка при этом повторно не открывается. Следующий тап по полю или нажатие `ArrowDown` / `ArrowUp` открывает шторку снова.
