<Title>v1.49.0</Title>

<Heading>Изменения</Heading>

**Button**

- Исправлен баг: иконка не перекрашивалась при наведении на кнопку, если курсор не находился ровно над иконкой или текстом (например, над паддингом кнопки).

**DocumentNumberEdit**

- Добавлено: `DocumentNumberEdit` пробрасывает `ref` на корневой элемент — раньше компонент был объявлен как `React.FC`, поэтому переданный `ref` терялся. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Проведён AI-рефакторинг: других изменений для потребителя нет.

**Skeleton**

- Добавлено: `Skeleton` пробрасывает `ref` на свой корневой `<div>` — раньше компонент был объявлен как `React.FC`, поэтому переданный `ref` терялся. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Проведён AI-рефакторинг, добавлен `displayName`: других изменений для потребителя нет.

**Spoiler**

- Проведён AI-рефакторинг: изменений для потребителя нет — публичный API и внешний вид прежние.

**Step**

- Добавлено: `Step` пробрасывает `ref` на корневой элемент (кружок шага) — раньше компонент был объявлен как `React.FC`, поэтому переданный `ref` терялся. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Проведён AI-рефакторинг: других изменений для потребителя нет.

**TextField**

- Добавлено: из пакета экспортируется тип `ITextFieldBaseProps` — общая база props для `TextField`, `MaskedField`, `AmountField` и `TextareaField`. Компонент `TextFieldBase` по-прежнему внутренний.
