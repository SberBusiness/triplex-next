<Title>v1.57.0</Title>

<Heading>Изменения</Heading>

**Button**

- В режиме `loading` заблокирована повторная активация кнопки по Enter и пробелу.

**DropdownDesktop**

- Проведён AI-рефакторинг.
- Исправлено: внешний `ref` больше не вызывается повторно на каждом рендере.
- Оптимизировано: прокрутка и изменение размеров окна не вызывают лишних рендеров, пока положение меню не изменилось; перерасчёт позиции откладывается, предыдущий запланированный вызов отменяется.
- Исправлено: закрытие одного из нескольких открытых меню больше не снимает блокировку клавиш прокрутки у остальных.

**FormFieldClear**

- Проведён AI-рефакторинг.

**FormFieldCounter / FormFieldDescription**

- Рефакторинг без изменений API. Раскладка описания со счётчиком включается до первой отрисовки, без кратковременного мигания.

**LightBox**

- При ширине окна до 767px включительно у `LightBox.Controls` добавлен нижний отступ 8px.

**ModalWindow**

- Анимация открытия и закрытия использует DOM-ссылку на контейнер. Это устраняет предупреждение о `findDOMNode` в StrictMode и ошибку при открытии на React 19.
- Вертикальная полоса прокрутки в `ModalWindow` теперь отображается только при переполнении содержимого.

**Совместимость с React**

- Пакет поддерживает React 18 и 19. Для проектов на TypeScript добавлены необязательные peer-зависимости `@types/react` и `@types/react-dom`. Для React 18 минимальная версия обоих пакетов типов — 18.3.4. Декларации для `big.js`, `react-text-mask` и `react-transition-group` устанавливаются вместе с Triplex.
- На React 19 компоненты, объединяющие внутренний и внешний ref, вызывают возвращённую потребителем функцию очистки при замене ref или размонтировании узла. Это касается в том числе `Suggest`, `ChipSuggest` и `ChipSuggestDropdown`.
