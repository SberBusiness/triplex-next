# NumberField

## Назначение

Однострочное поле для ввода числовой строки с плавающим лейблом, статусом, префиксом/постфиксом и описанием. При изменении ввода оставляет цифры, ведущий минус и один десятичный разделитель; точку заменяет запятой. Композиция: приватный `TextFieldBase` (семейство `FormField`) и приватный `NumberFieldInput` поверх `FormFieldInput`.

Используй когда: пользователь вводит произвольное целое или дробное число без денежного форматирования, ограничения точности и разделителей разрядов.

Не используй когда: нужна денежная сумма с форматированием и нормализованным значением (`AmountField`), произвольный текст (`TextField`), фиксированная маска (`MaskedField`) или только отображение числа без ввода.

## Варианты и props

`INumberFieldProps` наследует `ITextFieldProps`; собственных дополнительных props нет. `inputProps` передаётся в `NumberFieldInput`, остальные props — в `TextFieldBase`. Полный контракт атрибутов и слотов описан в `TextField-ai.md` и исходных интерфейсах.

### Обязательные props

| Prop | Назначение и ограничения |
|---|---|
| `inputProps` | Атрибуты и обработчики элемента ввода: `value`/`defaultValue`, `onChange`, `placeholder`, `id`, ARIA-атрибуты, `ref` и `render`. Для контролируемого ввода храни строку из `event.target.value`; это значение с запятой, а не нормализованная числовая строка с точкой. `inputProps.ref` указывает на `HTMLInputElement`. |

### Опциональные props

| Prop | По умолчанию | Назначение |
|---|---|---|
| `size` | `EComponentSize.LG` | Размер SM / MD / LG; наследуется вложенным input через `FormField`. |
| `status` | `EFormFieldStatus.DEFAULT` | DEFAULT / ERROR / WARNING / DISABLED. Статус DISABLED устанавливает нативный `disabled` на input. |
| `active` | `false` | Принудительно активное визуальное состояние; фокус input также делает поле активным. |
| `label` | — | Плавающий лейбл, связанный с input через `htmlFor`. |
| `prefix`, `postfix` | — | Контент слева и справа от input; кнопку очистки потребитель добавляет в `postfix` и сам сбрасывает значение. |
| `description`, `counter` | — | Описание и счётчик под полем, отображаются в общем блоке. |

`className`, `style`, data-атрибуты и другие div-атрибуты применяются к контейнеру `FormField` внутри `FormGroup`. Внешний `ref` указывает на этот же `<div>`; ссылка на input передаётся отдельно через `inputProps.ref`.

### Особенности поведения

- Фильтрация выполняется только при событии изменения ввода. Значения `value` и `defaultValue`, переданные снаружи, не нормализуются автоматически.
- Разрешены цифры `0`–`9`. Минус сохраняется только в начале исходной строки; другие символы удаляются. Ведущие нули остаются.
- Точка и запятая принимаются как десятичные разделители; в результате остаётся не более одной запятой. При повторном разделителе выбор зависит от каретки: разделитель справа от неё заменяет ранее найденный, остальные повторения игнорируются.
- Пустая строка и промежуточные значения `"-"`, `","`, `"-,"` допустимы. Компонент не проверяет завершённость числа, диапазон или количество дробных знаков и не преобразует строку в `number`.
- Перед вызовом `inputProps.onChange` изменяется `event.target.value`; обработчик получает тот же event с отфильтрованным значением. Если input в фокусе, каретка сдвигается на разницу длин исходной и отфильтрованной строк.
- По умолчанию рендерится текстовый `<input>`. Сохраняй текстовый тип для работы с запятой и кареткой; подходящий `inputMode` потребитель задаёт через `inputProps`.
- При использовании `inputProps.render` передавай предоставленные атрибуты, обработчики и ref своему input, чтобы сохранить фильтрацию и связь с `FormField`.

## Инварианты

- `forwardRef<HTMLDivElement, INumberFieldProps>` и `NumberField.displayName = "NumberField"` — не убирать. Внешний ref передаётся через `TextFieldBase` в `<div>` `FormField`; ref на input остаётся отдельным контрактом `inputProps.ref`. Оба поддерживают объектную и callback-форму.
- Имена `NumberField`, `INumberFieldProps`, унаследованные props, значения `EComponentSize`/`EFormFieldStatus` и barrel-экспорты — публичный API. Не менять без согласования.
- `NumberFieldInput` не экспортируется из barrel и не имеет отдельного AI.md: это приватная реализация фильтрации. Проверяй её поведение через публичный `NumberField`.
- Строковый контракт `inputProps.onChange` с запятой и промежуточными значениями сохраняется. Переход на числовое значение, точку или ограничения точности меняет поведение потребителя.
- Сохраняй композицию `TextFieldBase` / `FormFieldInput`, разделение контейнерных props и `inputProps`, а также общий блок `description`/`counter`.
- Story IDs и файлы baseline для `Sizes` и `Statuses` используются visual regression тестами; не переименовывать без синхронного обновления.
- Компонент и его зависимости должны оставаться совместимыми с React 17 для ветки `release-0`; не добавлять React 18-only API.

## Accessibility

- Input имеет стандартную текстовую семантику. Лейбл связывается с ним через `htmlFor` и `id`, переданный в `inputProps.id` либо сгенерированный `FormFieldInput`.
- Когда видимого лейбла нет, доступное имя задаёт потребитель через `inputProps["aria-label"]` или `inputProps["aria-labelledby"]`.
- `status={EFormFieldStatus.DISABLED}` блокирует input и исключает его из таб-обхода. `active` задаёт визуальное состояние и сам по себе не переводит фокус.
- `aria-invalid` и связь с описанием через `aria-describedby` потребитель передаёт через `inputProps`; статус ERROR не устанавливает эти атрибуты автоматически.
- Фокус и blur синхронизируются с `FormField`; пользовательские обработчики `inputProps.onFocus`/`onBlur` сохраняются. Для программного фокуса используй `inputProps.ref`.
- Отдельных обработчиков клавиш и роли `spinbutton` нет; клавиатурная навигация стандартная для `<input>`.

## Связанные компоненты

- `AmountField` — альтернатива для денежного ввода с разделителями разрядов, заданной точностью и нормализованным значением с точкой.
- `TextField` — источник наследуемого контракта `ITextFieldProps`. Его приватный `TextFieldBase` задаёт раскладку поля и слотов; отдельного AI.md у базы нет.
- `FormField` — семейство, обеспечивающее размер, статус, фокус, заполненность и связь лейбла с input. `NumberFieldInput` использует его `FormFieldInput`.
- `NumberFieldInput` — приватный слой фильтрации цифр, знака и десятичного разделителя с коррекцией каретки.
- `FormFieldClear` — необязательная кнопка очистки в `postfix`; пример `Production` очищает контролируемое значение и возвращает фокус в input.
