<Title>v1.43.0</Title>

<Heading>Новые компоненты</Heading>

**UnorderedListExtended**

- Расширенный маркированный список с типизированными элементами, пользовательскими маркерами, составным API и поддержкой `ref`.

<Heading>Ломающие изменения</Heading>

**Notification**

- Body.List: Удалено свойство `values`, теперь элементы списка необходимо передавать через свойство `items`.

**UnorderedList**

- Компонент полностью переведен на data-driven подход и больше не принимает `children`, теперь элементы списка необходимо передавать через свойство `items`.

<Heading>Изменения</Heading>

**Button**

- Исправлен баг, когда короткий текст в кнопке не центрировался.

**Carousel**

- Indicators: добавлено ограничение в максимум 5 индикаторов, при большем количестве страниц крайние элементы сжимаются в компактный edge-индикатор.
- Indicators: увеличен отступ между индикаторами c 4px до 8px.

**Checkbox**

- Проведён AI-рефакторинг.
- Исправлен баг, когда на тач-устройствах чекбокс залипал в состоянии ховера после тапа.

**CheckboxTreeExtended**

- Добавлено: экспортируется тип `ICheckboxTreeExtendedNodeProps` — теперь свойства `CheckboxTreeExtended.Node` можно использовать для типизации собственной обёртки узла.
- Исправлено: `className`, переданный в `CheckboxTreeExtended.Node`, больше не затирает собственный класс узла. Раньше вместе с ним пропадали отступы вложенной ветки — теперь классы объединяются.
- Проведён AI-рефакторинг, добавлен `displayName` у `CheckboxTreeExtended.Node`. Из разметки заголовка узла пропал глобальный класс `opened` — внешний вид не изменился.

**CheckboxXGroup**

- Проведён AI-рефакторинг.

**CheckboxYGroup**

- Проведён AI-рефакторинг.

**Chip**

- Изменен цвет токена `Chip.Background_Disabled` в темной теме.

**ChipGroup**

- Проведён AI-рефакторинг.

**LightBox**

- Исправлен баг, когда в состоянии `loading` `LightBox.TopOverlay` перекрывался `LoaderScreen`.

**SliderExtended**

- Добавлено: `SliderExtended` и его части (`Dot`, `Mark`, `Marks`, `Rail`, `Track`, `Tooltip`) пробрасывают `ref` на свой корневой элемент — тот же, что получает `className` и `...rest` (у `Tooltip` — обёртка подсказки).
- Исправлено: `className`, переданный в `SliderExtended` и `SliderExtended.Tooltip`, больше не затирает собственные классы элемента — раньше вместе с пользовательским классом пропадали размер и оформление. Затрагивает также `className` у `Slider` и `SliderRange`: он уходит на корневой элемент `SliderExtended`.
- Исправлено: `style`, переданный в `SliderExtended.Dot`, `SliderExtended.Track` и `SliderExtended.Mark`, больше не отбрасывается. Внутреннее позиционирование (`left`, `right`) по-прежнему приоритетно.
- Исправлено: `onClick`, переданный в `SliderExtended.Rail`, больше не отменяет перемещение ползунка по клику на полосу — вызываются оба обработчика.
- Изменено: слайдер отрисовывается сразу на первом рендере. Раньше шаги вычислялись в layout-эффекте, и первый кадр был пустым.
- Исправлено: если во время перетаскивания курсор уходил далеко за пределы полосы, ползунок прыгал в её противоположный конец. Теперь он остаётся на крайнем шаге.
- Исправлено: клик по полосе или по метке, когда ни один `SliderExtended.Dot` не отрисован, больше не выбрасывает исключение.
- Исправлено: при `min`, равном `max`, позиция ползунка больше не вычисляется как `NaN`.
- Добавлено: `displayName` у `SliderExtended.Tooltip`.
- Проведён AI-рефакторинг.

**StatusTracker**

- Минимальная высота изменена для десктоп экранов и добавлена для мобильных экранов.

**TabsExtended**

- Добавлено: `TabsExtended`, `TabsExtended.Content`, `TabsExtended.Content.TabsWrapper` и `TabsExtended.Content.DropdownWrapper` пробрасывают `ref` — раньше они были объявлены как `React.FC`. Ref указывает на тот же элемент, что получает `className` и `...rest`: у `TabsWrapper` это отображаемый контейнер табов, у `DropdownWrapper` — контейнер выпадающего списка.
- Исправлено: в `dropdownItemsIds` больше не попадают `null`. Дочерний элемент `TabsWrapper` без атрибута таба — например, `TabButton`, положенный напрямую, без `Tab`, — при нехватке ширины уезжал в render-prop `DropdownWrapper` как `null` и в одиночку раскрывал пустой Dropdown.
- Проведён AI-рефакторинг, добавлен `displayName`.

**UnorderedList**

- Элементы списка теперь поддерживают свойства `TTextProps` для гибкого управления стилями и параметрами текста.
- Для элементов списка добавлено свойство `marker` для кастомного отображения иконок и произвольных маркеров.
- Исправлено: маркер элемента центрируется по первой строке текста при любом размере типографики. Раньше вертикальные отступы маркера были рассчитаны на строку 20px (`B2`/`B3`), из-за чего на `B1` маркер смещался на 2px вверх, а на `B4` — на 2px вниз, и элемент `B4` занимал лишние 4px по высоте. Правка сделана в `UnorderedListExtended` и затрагивает оба списка.
- Проведён AI-рефакторинг. Публичный API и разметка не изменились.

**WindowResizeListener**

- Добавлено: интерфейс `IWindowResizeListenerProps` теперь экспортируется.
- Проведён AI-рефакторинг.
