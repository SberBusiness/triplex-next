# SmartSpot

## Назначение

Декоративная фигура на прозрачном фоне с настраиваемым цветом, размытием и анимацией. Подходит для фона экрана или карточки с результатом операции, например итогового экрана платежа. Несколько экземпляров можно расположить на одном слое и собрать из них подложку.

Не используй, когда нужен компактный индикатор статуса, сообщение пользователю или сплошная статичная заливка. Для индикации статуса подойдут `Marker`, `MarkerStatus` и `Badge`, для сообщения — `AlertProcess` или `AlertContext`, для заливки — CSS-свойство `background`.

## Варианты и props

| Prop        | По умолчанию | Описание                                                                                                             |
| ----------- | ------------ | -------------------------------------------------------------------------------------------------------------------- |
| `shape`     | `CIRCLE`     | Форма из `ESmartSpotShape`. Доступны круг, овал, квадрат и треугольник.                                              |
| `blur`      | `60`         | Радиус размытия фигуры в CSS px. При `blur={0}` края остаются чёткими.                                               |
| `animation` | `DRIFT`      | `DRIFT` двигает фигуру по эллипсу, `BREATHING` изменяет её масштаб от 0.9 до 1.1 и обратно, `NONE` фиксирует фигуру. |
| `distance`  | `50`         | Горизонтальный радиус траектории Drift в CSS px. Вертикальный радиус вдвое меньше.                                   |
| `duration`  | `6000`       | Длительность цикла анимации в мс.                                                                                    |

### Размер, позиция и композиция

- При стандартной ширине 160 px фигура вписана в область 160 × 160 px. Задай `width` через `className` или `style`, чтобы изменить размер. Для овала видимая область занимает 60% высоты. В CSS также можно задать высоту, позицию и прозрачность.
- Чтобы размыть композицию целиком, передай `blur={0}` каждой фигуре и примени CSS `filter: blur(...)` к общему слою. Если нужно обрезать размытие по границам композиции, задай `overflow: hidden` внешнему контейнеру.
- При смене `duration` сохраняется прогресс цикла. Новое значение `distance` применяется со следующего кадра. Смена `animation` начинает новый цикл.

## Дизайн-токены

У фигуры один токен заливки `SmartSpot.Background`. В светлой и тёмной темах он ссылается на `ColorSuccess.50`. Через `ThemeProvider` можно изменить цвет фигур в области темы: `tokens={{ SmartSpot: { Background: { ref: "ColorBrand.60" } } }}`.

Для отдельной фигуры задай `style.backgroundColor`, как у `Badge`. Например, `style={{ backgroundColor: DesignTokensCore.ColorBrand[60].value }}` переопределяет цвет из темы. Это значение применяется к самой фигуре под размытием, а остальные свойства `style` задают оформление корня.

## Инварианты

- Один экземпляр отрисовывает одну фигуру. Фон прозрачный, размытие и анимация могут выходить за границы корня.
- `forwardRef` направляет `ref` на корневой `div`. Туда же передаются `className`, `style` и HTML-атрибуты. `children` отсутствует в API.
- `NONE` не запускает `requestAnimationFrame`. Для анимированных пресетов кадры обновляют стили напрямую, без ререндеров React.
- Публичные экспорты компонента и enum'ов доступны из корня пакета.

## Accessibility

Фигура декоративная. Корневой элемент имеет `aria-hidden="true"` и пропускает события указателя. Для передачи статуса используй текст рядом с фигурой. Чтобы учитывать настройку пользователя `prefers-reduced-motion`, передай `animation={ESmartSpotAnimation.NONE}` по медиа-запросу на стороне потребителя.

## Связанные компоненты

Для компактной индикации статуса подходят `Marker`, `MarkerStatus` и `Badge`.
