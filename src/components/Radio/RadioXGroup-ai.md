# RadioXGroup

## Назначение

Контейнер для горизонтального расположения связанных `Radio` с переносом на следующую строку и настраиваемым отступом между вариантами. Сам контейнер не хранит выбранное значение и не управляет дочерними радио-кнопками.

Используй когда: варианты одного выбора нужно разместить в строку с переносами.
Не используй когда: варианты должны идти вертикально — используй `RadioYGroup`.

---

## Варианты и props

### Обязательные props

Обязательных custom-props нет. Для содержательной группы передай дочерние `Radio` и доступное имя группы.

### Опциональные props

| Prop | Тип | По умолчанию | Описание |
|---|---|---|---|
| `indent` | `TIndentSize` | `12` | Горизонтальный отступ между Radio в пикселях: `12`, `16`, `20`, `24`, `28`, `32`. |
| `children` | `React.ReactNode` | — | Содержимое группы, обычно непосредственные дочерние `Radio`. |
| `className`, `...rest` | `React.HTMLAttributes<HTMLDivElement>` | — | Пользовательский класс, HTML-атрибуты, ARIA-атрибуты и обработчики корневого `div`. |

### Ограничения использования

- Размер, выбранное и отключённое состояния задаются каждому `Radio`: у группы нет собственных `size`, `checked`, `disabled` или `onChange` для выбранного значения.
- Все `Radio` одного выбора должны иметь общий `name`. Разные группы должны использовать разные `name`: роль `radiogroup` сама по себе не связывает нативные input.
- Группа использует `inline-flex` и `flex-flow: row wrap`. Ширину и внешние отступы определяет окружающая разметка; отдельного вертикального зазора между строками нет.
- `indent` задаёт отрицательные горизонтальные маргины контейнера и положительные маргины по половине отступа у потомков с классом `.label` из `Radio`. Это не универсальный `gap`: для произвольных children без этого класса внутренние маргины не появятся, а отрицательные маргины контейнера останутся.
- `onChange`, унаследованный от HTML-атрибутов, получает всплывающий `React.FormEvent<HTMLDivElement>` от дочернего input. Значение читается из input-источника события; собственного callback-контракта выбора у группы нет.

## Дизайн-токены

Собственных дизайн-токенов нет: стили `RadioXGroup` задают только раскладку и отступы. Цвета и состояния дочерних радио-кнопок определяются компонентом `Radio`.

---

## Инварианты

- `forwardRef` обязателен; ref указывает на корневой `HTMLDivElement`.
- Корневой DOM-элемент — `div`, роль по умолчанию — `radiogroup`.
- `IRadioXGroupProps`, `indent`, значения `TIndentSize`, дефолт `12` и публичные barrel-экспорты сохраняются.
- Порядок `role="radiogroup"` перед `...rest` сохраняет существующий контракт: переданный `role` может переопределить роль по умолчанию.
- `className` объединяется через `clsx`, остальные HTML-атрибуты приходят на корневой элемент, `indent` в DOM не передаётся.
- LESS-классы `radioXGroup` и `indent-{n}`, геометрия маргинов и связь с `.label` из `Radio` должны сохраняться при рефакторинге.
- `displayName` — `RadioXGroup`. Компонент не добавляет state, контекст или клавиатурные обработчики.

---

## Accessibility

- Доступное имя группы задаёт потребитель через `aria-label` или `aria-labelledby` со ссылкой на существующий заголовок.
- По умолчанию `role="radiogroup"` обозначает группу радио-кнопок; при переопределении `role` ответственность за семантику остаётся у потребителя.
- `Radio` внутри группы сохраняют нативную семантику `input type="radio"`. Общий `name` обеспечивает единственный выбор и нативную клавиатурную навигацию между вариантами.
- Подписи и `disabled` передаются дочерним `Radio`. Контейнер не перемещает фокус и по умолчанию не добавляет `tabIndex`.

---

## Связанные компоненты

- `Radio` — часть семейства, рендерится потребителем внутри группы; его корневой `.label` участвует в горизонтальных отступах.
- `RadioYGroup` — альтернативная компоновка того же набора радио-кнопок по вертикали.
