<Title>v1.48.0</Title>

<Heading>Изменения</Heading>

**Calendar**

- Исправлена стилизация диапазона лет.

**ChipMonthYear / MonthYearPicker**

- Исправлен баг, когда в адаптивном режиме отображался `placeholder` вместо `label`.

**FormField**

- Исправлен баг, когда поле в фокусе при изменении статуса на `disabled` теряло фокус, но оставалось в состоянии `active`.

**LightBox**

- Исправлен баг, когда `LightBox.TopOverlay` был шире контента `LightBox`.

**Step**

- Добавлено: `Step` пробрасывает `ref` на корневой элемент (кружок шага) — раньше компонент был объявлен как `React.FC`, поэтому переданный `ref` терялся. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Проведён AI-рефакторинг: других изменений для потребителя нет.

**SuggestField**

- Проведён AI-рефакторинг: изменений для потребителя нет — публичный API и внешний вид прежние.

**Tabs**

- Добавлено: `Tabs` пробрасывает `ref` на корневой элемент (`<div role="tablist">`) и получил `displayName` — раньше компонент был объявлен как `React.FC`, поэтому переданный `ref` терялся. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Исправлено: строка табов больше не выпадает из обхода по `Tab` после смены `selectedId` извне или когда таб с фокусом уезжает в выпадающий список. Если выбранный таб в выпадающем списке, в таб-порядок попадает первый таб строки.
- Исправлено: поля таба `label` и `showNotificationIcon` больше не попадают в разметку как атрибуты контейнера таба — React перестал писать в консоль предупреждение о неизвестном атрибуте `showNotificationIcon`.
- Исправлено: пустой массив `tabs` больше не роняет компонент.
- Проведён AI-рефакторинг: других изменений для потребителя нет.

**TagColor**

- Проведён AI-рефакторинг: изменений для потребителя нет — публичный API и внешний вид прежние.

**TagGroup**

- Проведён AI-рефакторинг, добавлен `displayName`: других изменений для потребителя нет.

**UploadZone**

- Добавлено: интерфейс `IUploadZoneProps` экспортируется из пакета — раньше типизировать обёртку над `UploadZone` было нечем.
- Добавлено: `UploadZone.Input` (`UploadZoneInput`) пробрасывает `ref` на свой `<input type="file">` — раньше компонент был объявлен как `React.FC`, поэтому переданный `ref` терялся. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Исправлено: `displayName` у `UploadZone.Input` — был `UploadZone`, стал `UploadZoneInput`. Видно в React DevTools и в snapshot-тестах.
- Исправлено: при закрытии дроп-зоны в консоли больше не появляется предупреждение React «Attempted to synchronously unmount a root while React was already rendering».
- Проведён AI-рефакторинг: других изменений для потребителя нет.
