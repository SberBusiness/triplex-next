<Title>v1.44.0</Title>

<Heading>Изменения</Heading>

**Button**

- Изменен цвет токена `Button.SecondaryLight_Background_Active` в светлой и темной темах.

**Carousel**

- Indicators: добавлено ограничение в максимум 5 индикаторов, при большем количестве страниц крайние элементы сжимаются в компактный edge-индикатор.
- Indicators: увеличен отступ между индикаторами c 4px до 8px.
- Indicators: переходы ограничены первой и последней страницами.

**ExpandAnimation**

- Проведён AI-рефакторинг.

**Island**

- Добавлено свойство `withoutPaddings` для отображения компонента без отступов.

**IslandWidget**

- Внутренние отступы Header, Body и Footer теперь задаёт сам виджет, а не `Island`: размер передаётся субкомпонентам через контекст.

**Tabs**

- Добавлен фон для `TabButtonDropdown`, когда внутри дропдауна выбран элемент.
- Исправлено: `className`, переданный в `buttonDropdownAttributes`, больше не затирается собственными классами dropdown-кнопки — классы объединяются.
