<Title>v1.42.0</Title>

<Heading>Ломающие изменения</Heading>

**FormFieldMaskedInput**

- Prop `defaultValue` исключён из `IFormFieldMaskedInputProps` — поле контролируемое, начальное значение задаётся через `value`. Затрагивает также `MaskedField.maskedInputProps` и `DropdownMobileMaskedInput`.

**MaskedField**

- Тип `maskedInputProps.ref` изменён с `React.RefObject<HTMLInputElement>` на `React.RefObject<HTMLDivElement>` — ref указывает на `<div>`-обёртку поля. Для ссылки на `<input>` используйте `maskedInputProps.forwardedRef`.

<Heading>Изменения</Heading>

**AlertProcess**

- Исправлено: `className` в `AlertProcess.Spoiler` больше не затирает собственные классы элемента — раньше вместе с пользовательским классом пропадала анимация раскрытия.
- Исправлено: `AlertProcess.Spoiler` теперь пробрасывает `ref` — на элемент раскрываемого контента.
- Изменено: из разметки `AlertProcess.Spoiler` убрана пустая обёртка-`<div>`, корневым элементом стал элемент контента. Визуально ничего не изменилось, но CSS-селекторы и поиск по DOM, опирающиеся на этот уровень вложенности, нужно поправить.
- Добавлено: на кнопке раскрытия `AlertProcess.Spoiler` выставляется `aria-expanded`.

**ComposedKeyDownListener**

- Исправлено: смена набора горячих клавиш больше не перемонтирует содержимое — раньше при изменении `keyDownListeners` пересоздавались DOM-узлы `children` и терялись введённые значения инпутов, фокус и текущие анимации.
- Изменено: слушатели композитора подписываются на `window` раньше `children`, а не после них. Если внутри `children` есть собственный глобальный `keydown`-обработчик той же клавиши, `onMatch` сработает раньше него — важно для кода, который полагается на этот порядок или на `stopImmediatePropagation`.

**FormFieldMaskedInput**

- Исправлено: поле перестало писать в консоль предупреждение React «input contains both value and defaultValue props».

**LoaderSmall**

- AI-рефакторинг: enum `ELoaderSmallSize` помечен в документации как legacy — размер задаётся через `EComponentSize`. Публичный API и поведение не изменены.

**MaskedField**

- AI-рефакторинг: в Storybook добавлены примеры `WithPlaceholderMask` и `PassRefToInput`. Поведение и разметка компонента не изменились, изменения типов — см. «Ломающие изменения».

**MobileView**

- AI-рефакторинг: добавлены примеры в Storybook. Публичный API и поведение не изменены.
