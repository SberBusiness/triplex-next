<Title>v1.42.0</Title>

<Heading>Ломающие изменения</Heading>

**FormFieldMaskedInput**

- Prop `defaultValue` исключён из `IFormFieldMaskedInputProps` — поле контролируемое, начальное значение задаётся через `value`. Затрагивает также `MaskedField.maskedInputProps` и `DropdownMobileMaskedInput`.

**MaskedField**

- Тип `maskedInputProps.ref` изменён с `React.RefObject<HTMLInputElement>` на `React.RefObject<HTMLDivElement>` — ref указывает на `<div>`-обёртку поля. Для ссылки на `<input>` используйте `maskedInputProps.forwardedRef`.

<Heading>Изменения</Heading>

**AlertProcess**

- Исправлено: `className`, переданный в `AlertProcess.Spoiler`, больше не затирает собственные классы элемента — раньше вместе с пользовательским классом пропадала анимация раскрытия.
- Исправлено: `AlertProcess.Spoiler` пробрасывает `ref` — на элемент раскрываемого контента, то есть на тот же элемент, что получает `...rest`.
- Изменено: из разметки `AlertProcess.Spoiler` убрана пустая обёртка-`<div>`, корневым элементом стал элемент раскрываемого контента. Визуально ничего не изменилось, но код, опиравшийся на лишний уровень вложенности в CSS-селекторах или в поиске по DOM, нужно поправить.
- Добавлено: на кнопке раскрытия `AlertProcess.Spoiler` выставляется `aria-expanded` — состояние раскрытия доступно скринридерам.
- Проведён AI-рефакторинг.

**Amount**

- Добавлено: `Amount` пробрасывает `ref` — компонент был объявлен как `React.FC`. Теперь это `forwardRef`, ref указывает на корневой `<span>`, то есть на тот же элемент, что получает `className` и `...rest`. Изменение аддитивное: форма `IAmountProps` не поменялась.
- Проведён AI-рефакторинг.

**Badge**

- Проведён AI-рефакторинг.

**Body**

- Проведён AI-рефакторинг. Публичный API, разметка и внешний вид не изменились.

**ComposedKeyDownListener**

- Исправлено: смена набора горячих клавиш перемонтировала содержимое — `children` пересоздавались вместе с DOM-узлами и теряли введённые значения инпутов, фокус и текущие анимации. Теперь структура React-дерева не зависит от длины и порядка `keyDownListeners`, содержимое остаётся смонтированным.
- Изменился относительный порядок подписок на `window`: слушатели композитора монтируются раньше `children`, а не после них. Если внутри `children` есть собственный глобальный `keydown`-обработчик той же клавиши, `onMatch` сработает раньше него, а не позже — важно для кода, который полагается на этот порядок или на `stopImmediatePropagation`. Итоговый DOM и порядок вызова `onMatch` внутри `keyDownListeners` прежние.

**FormFieldMaskedInput**

- Исправлено: поле перестало писать в консоль предупреждение React «input contains both value and defaultValue props».

**Island**

- Расширение API: свойства `loading` и `loaderScreenProps`. При `loading` поверх контента карточки показывается `LoaderScreen` типа `middle`, настраиваемый через `loaderScreenProps`.

**DateField / MonthYearField**

- Добавлено ограничение по минимальной ширине.

**LoaderSmall**

- Проведён AI-рефакторинг; экспортируемый `ELoaderSmallSize` помечен как legacy — размер задаётся `EComponentSize`.

**MaskedField**

- Проведён AI-рефакторинг. Поведение и разметка не изменились, изменения типов — см. «Ломающие изменения».

**MediaWidth**

- Проведён AI-рефакторинг, добавлен `displayName`.

**FormFieldMaskedInput**

- Исправлен выход подложки-плейсхолдера за границы контейнера при нехватке свободного места.

**MobileView**

- Проведён AI-рефакторинг, добавлен `displayName`.

**Pagination**

- Внутри `MasterTable` в состоянии `loading` элементы пагинации становятся неактивными - кнопки навигации и номера страниц получают `disabled`, селект количества строк не открывается.
- Исправлена обработка `status` в `PaginationSelect`.

**SuggestField**

- Исправлен баг, при котором свойства `prefix`/`postfix`/`description`/`counter` не прокидывались в адаптивном режиме.
