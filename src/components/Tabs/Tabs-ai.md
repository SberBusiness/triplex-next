# Tabs

## Назначение

Готовые табы-переключатели поверх `TabsExtended`: компонент принимает массив табов, сам собирает разметку, сам рендерит кнопку выпадающего списка для не поместившихся табов и сам обрабатывает навигацию стрелками.

Используй когда: нужен типовой набор табов «лейбл + опциональный значок уведомлений» — это первый выбор для обычной задачи.
Не используй когда:

- содержимое таба нестандартное (своя разметка, свой триггер выпадающего списка) — бери `TabsExtended`, `Tabs` собран поверх него;
- нужны табы-подчёркивания в шапке раздела — бери `TabsLine`;
- нужен набор переключателей без семантики табов — это не задача компонента.

## Варианты и props

`ITabsProps` расширяет `ITabsExtendedProps` (а тот — `React.HTMLAttributes<HTMLDivElement>`). Неизвестные компоненту атрибуты уходят на корневой `<div>` с `role="tablist"`.

### Обязательные props

| Prop | Тип | Описание |
|---|---|---|
| `tabs` | `Array<ITabsItem>` | Состав табов. Порядок массива = порядок в строке и порядок обхода стрелками |
| `selectedId` | `string` | Id выбранного таба. Компонент полностью управляемый: своего состояния выбора у него нет |
| `onSelectTab` | `(selectedId: string) => void` | Запрос на смену выбранного таба. Вызывается **только** если выбирают таб, отличный от `selectedId` — и из строки, и из выпадающего списка |

### Опциональные props

| Prop | Тип | По умолчанию | Описание |
|---|---|---|---|
| `type` | `ETabsExtendedType` | `TYPE_1` | Тип оформления, выбирается по фону **страницы**: `TYPE_1` — серый фон контейнера, для белой страницы; `TYPE_2` — белый фон контейнера, для затенённой страницы |
| `size` | `EComponentSize` | `MD` | Один prop на весь компонент: задаёт и контейнер, и кнопки табов, и кнопку выпадающего списка (в отличие от `TabsExtended`, где размеры независимы) |
| `buttonDropdownAttributes` | `React.ButtonHTMLAttributes<HTMLButtonElement>` | — | HTML-атрибуты кнопки выпадающего списка. Сюда передаётся `aria-label`; переданный `className` мерджится с собственными классами кнопки, не затирая их |
| `children` | `never` | — | Запрещены типом: состав задаётся только через `tabs` |

### Поля элемента `tabs` (`ITabsItem`)

`ITabsItem` расширяет `Omit<ITabsExtendedTabProps, "children" | "onSelect">`, то есть принимает и HTML-атрибуты контейнера таба (`<span>`).

| Поле | Тип | Описание |
|---|---|---|
| `id` | `string` | Id таба. Сопоставляется с `selectedId` и приходит в `onSelectTab` |
| `label` | `React.ReactNode` | Содержимое кнопки таба |
| `showNotificationIcon` | `boolean` | Значок новых уведомлений (`Badge.Dot`) на кнопке таба и на пункте выпадающего списка |

### Ограничения

- `label` и `showNotificationIcon` — поля кнопки таба, на контейнер таба они не уходят; остальные поля элемента считаются HTML-атрибутами `<span>`-контейнера.
- Компонент не хардкодит текст: без `buttonDropdownAttributes["aria-label"]` кнопка выпадающего списка остаётся без доступного имени.
- Выпадающий список рендерится всегда, но скрыт (`hidden`), пока все табы помещаются в строку.
- `id` табов должны быть уникальными: по ним идёт и сопоставление с `selectedId`, и React-ключи, и замеры ширины.

Переопределяются через `ThemeProvider` (prop `tokens`) — см. `ThemeProvider-ai.md` →
«Как переопределять токены». Значения по умолчанию — `src/components/DesignTokens/components/Tabs.ts`.

Собственные стили компонента — только подсветка кнопки выпадающего списка, когда выбранный таб уехал в список:

```text
Tabs.Type1_Tab_Background_Selected
Tabs.Type2_Tab_Background_Selected
```

Оформление контейнера и самих кнопок табов приходит из `TabsExtended` — он использует всё семейство токенов `Tabs`, общее для обоих компонентов.

## Инварианты

- `Tabs` объявлен как `React.FC`, **без `forwardRef` и без `displayName`** — в отличие от `TabsExtended` и его субкомпонентов. Это расхождение с правилом «forwardRef обязателен»: добавление ref меняет публичный API и тип компонента, поэтому делается отдельной согласованной задачей, а не походя.
- Публичные имена `ITabsProps`, `ITabsItem`, `Tabs` и barrel `src/components/Tabs/index.ts` — часть публичного API.
- Компонент строится на `TabsExtended` и опирается на флаги `isFirstInlineTab` / `isLastInlineTab` из render-prop `Tab`: на них держатся границы навигации стрелками. Изменение их семантики ломает клавиатуру `Tabs`.
- Класс `.tabButtonDropdown` согласует высоту кнопки выпадающего списка с высотой кнопки таба (SM — 20px, MD — 32px, LG — 40px). Без него `ButtonDropdown` выше таба того же размера и растягивает и контейнер, и сами табы.
- `label` и `showNotificationIcon` обязаны вырезаться из элемента `tabs` перед спредом на `TabsExtended.Content.Tab`: иначе они уходят на `<span>` как неизвестные DOM-атрибуты, и React пишет предупреждение в консоль. Зафиксировано unit-тестом.
- Массив `tabs` может быть пустым — компонент не должен падать (поэтому начальный id фокусируемого таба читается через optional chaining).

## Accessibility

- Роли приходят из `TabsExtended`: корневой элемент — `role="tablist"`, кнопка таба — `<button role="tab">` с `aria-selected`, контейнер таба — `role="presentation"`.
- **Roving tabindex:** в таб-порядок страницы попадает ровно один таб (`tabIndex = 0`), остальные получают `tabIndex = -1`. Начальное значение — выбранный таб (или первый, если `selectedId` пуст), дальше «активный» таб переносится стрелками.
- **Клавиатура:** `ArrowLeft` / `ArrowRight` переносят фокус на соседний таб **в строке** и делают его единственным табом с `tabIndex = 0`. На краях строки фокус остаётся на месте (переноса на противоположный край нет). Для обеих стрелок вызывается `preventDefault` — чтобы страница не скроллилась; другие клавиши компонент не перехватывает.
- Выбор таба — нативной активацией `<button>` (`Enter` / `Space`) и кликом. Стрелки только перемещают фокус и **не меняют** выбранный таб.
- Табы, уехавшие в выпадающий список, скрыты через `display: none` и из обхода клавиатурой выпадают: попасть в них можно только через список.
- `aria-label` кнопки выпадающего списка задаёт потребитель через `buttonDropdownAttributes` — компонент текста не хардкодит.
- `aria-controls` и связку с панелью контента компонент не выставляет: если табы переключают панели, их `id` и `aria-controls` проставляет потребитель.
- Известное ограничение: `tabIndex = 0` привязан к табу, запомненному при первом рендере и при навигации. Если выбранный таб меняется извне или «активный» таб уезжает в выпадающий список, ни у одного таба в строке может не остаться `tabIndex = 0` — тогда строка табов пропускается при обходе `Tab`.

## Связанные компоненты

- `TabsExtended` — база: `Tabs` рендерит его субкомпоненты и наследует от его интерфейсов (`ITabsProps extends ITabsExtendedProps`, `ITabsItem extends Omit<ITabsExtendedTabProps, ...>`). Туда же уходят за нестандартной разметкой табов.
- `TabsLine` — альтернативный визуальный паттерн табов (подчёркивание вместо залитой кнопки).
- `ButtonDropdown` — кнопка выпадающего списка, которую `Tabs` рендерит сам для не поместившихся табов; тема подбирается по `type` (`DOTS_SECONDARY` / `DOTS_SECONDARY_LIGHT`).
- `Badge` — `Badge.Dot` как значок новых уведомлений на кнопке таба (рендерится внутри `TabsExtended.Content.TabButton`).
