<Title>v1.46.0</Title>

<Heading>Изменения</Heading>

**CardAction**

- Исправлен аргумент `onToggle` в неконтролируемом режиме: колбэк получает актуальное состояние выбора. Раньше при нескольких переключениях в одном пакете обновлений React (например, два вызова `handleToggle` подряд через `ref`) все вызовы `onToggle` получали одно и то же значение, не совпадающее с итоговым состоянием карточки. Одиночное переключение по клику, `Enter` или `Space` работает как прежде.
- Проведён AI-рефакторинг: других изменений для потребителя нет.

**ChipMultiselect**

- Проведён AI-рефакторинг: изменений для потребителя нет.

**ChipOptions**

- Добавлен prop `clearButtonProps` — props кнопки сброса выбора (`aria-label`, `disabled`, `className`, `data-*`). Размер кнопки по-прежнему задаётся `size` чипса и в тип не входит. Переданные `onClick` и `onKeyDown` не заменяют собственные обработчики компонента, а вызываются после них.
- `Enter` и `Space`, нажатые на кнопке сброса, больше не всплывают до чипса: `Space` теперь активирует кнопку, а внешний `onKeyDown` чипса не срабатывает заодно со сбросом.
- Проведён AI-рефакторинг: других изменений для потребителя нет.

**ChipSort**

- Проведён AI-рефакторинг: изменений для потребителя нет.

**ChipSuggest**

- Проведён AI-рефакторинг: `ChipSuggest` больше не оборачивает переданный `ref` в новую функцию на каждый рендер, поэтому стабильный callback-`ref` перестал переприкрепляться (элемент, на который указывает `ref`, прежний). Других изменений для потребителя нет.

**DateField**

- Проведён AI-рефакторинг, добавлен `displayName` у внутреннего управляющего элемента поля.

**HelpBox**

- Проведён AI-рефакторинг: `HelpBox` больше не оборачивает переданный `ref` в новую функцию на каждый рендер, поэтому стабильный callback-`ref` перестал переприкрепляться. Автогенерируемый `id` подсказки теперь имеет вид `HelpBox-<n>` вместо `:r<n>:`. Других изменений для потребителя нет.
- Исправлен баг, когда компонент при открытии наведением мыши перехватывал фокус у полей ввода, внутри которых находился.

**IslandAccordion**

- Проведён AI-рефакторинг: при `num={0}` со `status` в заголовке больше не появляется текст «0» (кружок шага, как и прежде, не рендерится). Автогенерируемые `id` заголовка и раскрывающейся области теперь имеют вид `IslandAccordionItem-<n>-header` и `IslandAccordionItem-<n>-body`. Смена `opened` применяется в том же рендере, без промежуточного кадра со старым состоянием. Других изменений для потребителя нет.

**TextareaField**

- `height` заменен на `min-height`.
