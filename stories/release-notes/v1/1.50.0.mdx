<Title>v1.50.0</Title>

<Heading>Ломающие изменения</Heading>

**SuggestField**

- Изменено: выбранное значение сбрасывается только кнопкой очистки — на десктопе и на мобильном одинаково. Раньше при `clearInputOnFocus` значение терялось от простого фокуса без выбора: на десктопе focus → blur, на мобильном открытие → закрытие дропдауна. Теперь потеря фокуса на десктопе и закрытие дропдауна без выбора на мобильном `onSelect(undefined)` не вызывают, даже если поле ввода пустое: в поле возвращается `label` текущего `value`.
- Изменено: на мобильном кнопка очистки сама сбрасывает значение — вызывает `onSelect(undefined)` и `onFilter("")` (если поле не пустое), затем `onClear`, как на десктопе. Раньше вызывался только `onClear`.
- Кнопка очистки рендерится, только если передан `onClear`. Без него встроенного способа сбросить значение нет: если поле необязательное, передайте `onClear`.

<Heading>Изменения</Heading>

**ButtonDropdownExtended**

- Добавлены горизонтальные отступы `12px` между соседними `ButtonDropdownExtended`, а также между `ButtonDropdownExtended` и `Button` в обоих порядках.

**Radio**

- Проведён AI-рефакторинг.

**RadioXGroup**

- Добавлена поддержка `ref` на корневой контейнер (`HTMLDivElement`).

**RadioYGroup**

- Добавлено: `RadioYGroup` передаёт `ref` на корневой `<div>`. Тип компонента изменился с `React.FC` на `React.ForwardRefExoticComponent`.

**SuggestField**

- Исправлен баг: на мобильной ширине терялись `className`, `id`, `data-test-id`, `active` и `renderInput` — `SuggestField` передавал мобильному варианту только часть props. Теперь оба варианта получают одинаковый набор props, в том числе `data-test-id` для e2e.
