<Title>v0.41.0</Title>

<Heading>Ломающие изменения</Heading>

**FormField**

- `statusToClassNameMap` больше не экспортируется — ни из `components/FormField`, ни из корня пакета. Маппинг статуса на CSS-класс переименован во внутреннюю константу `STATUS_TO_CLASS_NAME_MAP` и стал деталью реализации компонента. Воспроизвести его на стороне потребителя нельзя: имена классов хешируются при сборке вместе с версией библиотеки (`error` → `error__58eeaf1b`) и меняются от релиза к релизу. Визуальное состояние поля задаётся prop `status` у `FormField` — используйте его; если нужно опереться на состояние в собственных стилях, навешивайте свой класс рядом.

<Heading>Изменения</Heading>

**Calendar**

- Изменён цвет muted/disabled дня/месяца/года в тёмной теме.
- AI-рефакторинг: JSDoc на props и внутренних компонентах, codestyle-чистка, unit-тесты (Calendar, CalendarViewItem, utils), создан `Calendar-ai.md`. Публичный API не изменён; внутренний `CalendarFooter` теперь применяет объявленные, но ранее игнорировавшиеся `className` и `...rest`.
- Исправлено: для `pickType={ECalendarPickType.MONTH_YEAR}` внешняя смена `pickedDate` на другой месяц выставляла заголовок в формате «March 1970» вместо «1970» — до следующего перелистывания. Заголовок теперь всегда форматируется по текущему виду отображения.
- Исправлено: после смены страницы с клавиатуры (`PageUp` / `PageDown`) фокус не возвращался на новую tabbable-ячейку, если она занимала ту же позицию сетки (в видах месяцев и годов — всегда). Фокус восстанавливается только когда он уже находился внутри сетки — программная смена страницы фокус не забирает.
- Исправлено: выбор первой tabbable-ячейки страницы (когда `pickedDate` вне страницы, а начальные даты отключены) перебирал кандидатов с накоплением шага (0, +1, +3, +6…), а в виде годов прибавлял месяцы вместо лет — tabbable-ячейкой могла стать не первая доступная дата, либо она не назначалась вовсе.
- Расширение API: поля `dateFrom` / `dateTo` в `IDateLimitRange` стали опциональными — типы приведены к фактическому поведению: незаданная граница берётся из `globalLimitRange`. Внешнему TS-коду, читающему эти поля, может потребоваться проверка на `undefined`.
- Расширение API: функциональный вариант `dayHtmlAttributes` теперь допускает возврат `data-*` атрибутов (`TTdHTMLAttributesWithData`) — как и объектный вариант. Функции с явной аннотацией возврата старым типом `React.TdHTMLAttributes<…>` нужно перевести на `TTdHTMLAttributesWithData`.

**CardAction, CardStatic**

- В `ECardRoundingSize` добавлено значение `LG` — скругление 24px. Существующие `MD` (16px) и `SM` (8px) не изменились, значение по умолчанию осталось `MD`.

**Chip**

- AI-рефакторинг: JSDoc на props (у `size` и `type` в описании указаны значения по умолчанию) и на внутреннем обработчике клавиатуры, константы-маппинги типа и размера приведены к общему стилю именования, упрощены условия формирования классов, unit-тесты расширены с 5 до 22 кейсов. Публичный API, DOM и визуальное поведение не изменены.
- `children` явно объявлен в `IChipProps` — тип прежний (раньше приходил из `React.HTMLAttributes`), но у prop появилось описание в подсказках IDE и в таблице props.

**FocusTrapExtended**

- Оптимизировано управление стеком ловушек фокуса во вложенных окнах за счет перевода активного инстанса на контролируемую паузу вместо его деактивации.

**FormField**

- Исправлено: `className`, переданный в `FormFieldDescription` или `FormFieldCounter`, затирал базовый класс компонента вместо того, чтобы дополнять его. Теперь классы объединяются, как у остальных компонентов библиотеки.
- AI-рефакторинг: документация props и значений `EFormFieldStatus`, внутренние упрощения и расширенные unit-тесты. Охвачены `FormFieldInput`, `FormFieldLabel`, `FormFieldPrefix`, `FormFieldPostfix`, `FormFieldClear`, `FormFieldDescription`, `FormFieldCounter`. Остальной публичный API не изменён.

**IconWrapper**

- AI-рефакторинг: JSDoc на props, расширены unit-тесты. Публичный API и поведение не изменены.

**Island**

- Исправлено: `className`, переданный в `IslandHeader` (`Island.Header`) или `IslandFooter` (`Island.Footer`), затирал базовый класс компонента вместо того, чтобы дополнять его. Теперь классы объединяются, как в `IslandBody` и у остальных компонентов библиотеки. Это влияет на любой код, передающий `className` в эти части: базовый класс остаётся на элементе, поэтому к нему снова применяются отступы `Island` и `position: relative` из стилей части. Последнее меняет containing block — абсолютно спозиционированные потомки внутри такой части теперь позиционируются относительно неё, а не относительно ближайшего внешнего positioned-предка. Компоненты самой библиотеки выглядят как прежде: единственный затронутый — `IslandAccordion`, в его стилях отступ Island погашен явно.
- AI-рефакторинг: JSDoc на props, значениях `EIslandType` и субкомпонентах, `displayName` у `IslandHeader`, `IslandBody`, `IslandFooter`, добавлены unit-тесты. Публичный API не изменён (props, значения enum, barrel-экспорты, `forwardRef` — как были).

**KeyDownListener**

- AI-рефакторинг: JSDoc на props, обработчик нажатия сведён к одной проверке кода клавиши, в `ComposedKeyDownListener` убрано приведение типа `children` и добавлен `displayName`, добавлены unit-тесты и stories. Существующий публичный API не изменён (props, их типы, class-компонент `KeyDownListener` с публичным методом `handleKeyDown` — как были).
- Интерфейс props `IComposedKeyDownListenerProps` теперь экспортируется из пакета — можно типизировать собственные обёртки над `ComposedKeyDownListener`.
- Исправлено: `ComposedKeyDownListener` с пустым `keyDownListeners` и без `children` больше не возвращает `undefined` из рендера — на React 17 это приводило к ошибке «Nothing was returned from render».

**LoaderMiddle**

- AI-рефакторинг: JSDoc на компоненте, порядок импортов приведён к codestyle, в стилях объединены дублирующиеся базовые правила точек и обегающей линии, unit-тесты расширены с 1 до 2 кейсов, создан `LoaderMiddle-ai.md`. В stories `controls: { disable: true }` перенесён на верхний уровень `parameters` — внутри `docs` он не применялся. Публичный API и поведение не изменены (props, DOM-разметка, `role="status"`, токены — как были).

**LoaderScreen**

- AI-рефакторинг: JSDoc на компоненте, props и `ILoaderScreenMiddleProps` (у `size` указано значение по умолчанию), соответствие типа лоадера классу подложки вынесено в константу-маппинг, порядок импортов и позиция `className` в `clsx` приведены к общему стилю, unit-тесты расширены с 6 до 15 кейсов, создан `LoaderScreen-ai.md`. Публичный API, DOM и визуальное поведение не изменены — изменился только порядок классов внутри атрибута `class` корневого элемента (набор классов тот же, на каскад не влияет).

**StatusTracker**

- Добавлены токены `StatusTracker.Background` и `StatusTracker.Draft_Color`.
- Токен `StatusTracker.Draft_Background` теперь задает цвет подсветки статуса `draft`.
- Изменены цвета токенов `StatusTracker.Draft_Background`, `StatusTracker.Draft_Color`, `StatusTracker.Rejected_Color` в светлой и темной темах.
- Минимальная высота изменена для десктоп экранов и удалена для мобильных экранов.

**ThemeProvider**

- AI-рефакторинг: JSDoc на props, значениях `ETriplexNextTheme` и полях контекста темы, ключ тега стилей с css-переменными вынесен в отдельный хелпер (раньше строка собиралась в двух местах), упрощён эффект навешивания `scopeClassName` — убран дублирующий его ref. Добавлены unit-тесты на `ThemeProviderView` и `useToken`. Публичный API, DOM и поведение не изменены.

**Tooltip**

- Исправлено: подсказка, смонтированная сразу открытой (управляемый режим `isOpen`), не закрывалась по действию мышью вне неё — при монтировании навешивался обработчик `click`, а снимался `mousedown`.
- Исправлено: класс темы больше не снимается с контейнера, если в течение задержки закрытия подсказку открыли снова или контейнер занял другой `Tooltip`.
- Исправлено: в адаптивном (мобильном) режиме свойства `size` и `alignTip` больше не уходят в DOM — React больше не предупреждает о нераспознанном атрибуте `alignTip`.
- Исправлено: при размонтировании открытой подсказки с `toggleType="hover"`, а также при смене `toggleType` на лету обработчики наведения снимаются и навешиваются и на саму подсказку, а не только на целевой элемент.
- AI-рефакторинг: разбор `children` вынесен в чистую функцию и мемоизирован, значение контекста стабилизировано, дедуплицирована разметка `Tooltip.Link`, из расчёта координат убрано двойное приведение типов, в хуке темы вынесен хелпер и добавлен guard при размонтировании, `displayName` внутреннего `TooltipDesktopBase` приведён к имени класса, добавлены JSDoc на props и приватные методы, добавлены unit-тесты. Публичный API не изменён (props, значения enum, barrel-экспорты, `forwardRef` — как были).
