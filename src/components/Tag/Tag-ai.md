# Tag

## Назначение

Тег — компактная плашка с выбранным значением параметра и кнопками управления им: удалением
и, опционально, редактированием. Типичное место — строка применённых фильтров или список выбранных
в форме значений, где пользователь должен видеть выбор и уметь его снять.

Используй когда: значение выбрано пользователем и его нужно показать вместе с возможностью убрать
или изменить.
Не используй когда: нужна неинтерактивная цветная метка статуса — это `TagColor`, у него нет кнопок,
но есть `status`. Нужен интерактивный элемент выбора фильтра (открывает выпадающий список,
хранит выбор) — это семейство `Chip`.

## Варианты и props

### Обязательные props

| Prop | Тип | Описание |
|---|---|---|
| `id` | `string` | Идентификатор тега. Уходит аргументом в `onEdit` и `onRemove` — по нему потребитель понимает, какой тег группы изменили. Атрибутом `id` на корневой элемент НЕ попадает: он деструктурируется из props и в `...restProps` не входит |
| `size` | `EComponentSize` | Размер: SM (высота 20px) / MD (28px) / LG (32px). Задаёт высоту, внутренние отступы, размер текста (`ETextSize.B4` / `B3` / `B2`) и размер иконок (16 / 20 / 24) |

### Опциональные props

| Prop | Тип | По умолчанию | Описание |
|---|---|---|---|
| `children` | `React.ReactNode` | — | Контент тега. Рендерится внутри `Text`, длинный текст обрезается многоточием |
| `disabled` | `boolean` | `false` | Текст переключается на `EFontType.DISABLED`, обе кнопки получают `disabled` |
| `onEdit` | `(id: string) => void` | — | Колбэк редактирования. **Управляет наличием кнопки редактирования** — без него кнопка не рендерится |
| `onRemove` | `(id: string) => void` | — | Колбэк удаления. На наличие кнопки удаления НЕ влияет — она рендерится всегда |
| `editButtonProps` | `IButtonIconProps` | — | Props кнопки редактирования. Здесь потребитель задаёт `aria-label` |
| `removeButtonProps` | `IButtonIconProps` | — | Props кнопки удаления. Здесь потребитель задаёт `aria-label` |

Остальные props — стандартные атрибуты `span` (`ITagProps extends React.HTMLAttributes<HTMLSpanElement>`),
уходят на корневой элемент через `...restProps`.

### Асимметрия кнопок

Две кнопки живут по разным правилам, и это легко перепутать:

- кнопка **редактирования** рендерится только при переданном `onEdit`;
- кнопка **удаления** рендерится всегда, даже без `onRemove` — тогда клик по ней просто ничего
  не делает.

### Порядок обработчиков клика

`onClick` внутри `editButtonProps` / `removeButtonProps` не заменяет `onEdit` / `onRemove`,
а вызывается **после** него: компонент вынимает `onClick` из этих props и вешает на кнопку
собственный обработчик, который сначала зовёт колбэк тега, потом пользовательский `onClick`.

## Дизайн-токены

```
--triplex-next-Tag-Background
```

Единственный собственный токен — фон плашки. Цвет текста задаёт `Text` через токены типографики
(`Typography-Primary_Color` / `Typography-Disabled_Color`), цвет иконок — палитра
`@sberbusiness/icons-next` (`paletteIndex={5}`), кольцо фокуса кнопок — `ButtonIcon`
(`Button-Icon_Shadow_Focus`).

Размерные значения (высоты 20/28/32px, отступы, `border-radius: 4px`, `gap: 2px`) заданы литералами
в `styles/Tag.module.less` — они специфичны для компонента.

## Инварианты

- `forwardRef<HTMLSpanElement>` — не убирать. Ref всегда указывает на корневой `<span>`.
- Корневой элемент — `<span>` (тег инлайновый, встаёт в строку текста и в `TagGroup`).
  Менять на `div` нельзя.
- `displayName` — `"Tag"`. Не менять.
- `id` не попадает на корневой элемент. Это часть наблюдаемого поведения: потребители, которым
  нужен DOM-идентификатор, ставят его отдельным атрибутом. Пробросить `id` в разметку —
  breaking change.
- Кнопка удаления рендерится безусловно, вне зависимости от `onRemove` — менять на условный
  рендер нельзя без согласования, это изменит вёрстку у потребителей, не передающих `onRemove`.
- Порядок в DOM: текст → кнопка редактирования → кнопка удаления. На него опираются потребители,
  выбирающие кнопки по индексу, и скриншот-тесты.
- Собственный `onClick` тега на кнопках всегда вызывается раньше пользовательского
  `onClick` из `*ButtonProps`.
- Компонент не хардкодит текстовые строки: `aria-label` / `title` кнопок задаёт потребитель.
  Библиотека мультиязычная.
- Экспорты `Tag` и `ITagProps` идут в barrel `src/components/Tag/index.ts` — сохранять.
- Ширина ограничена контейнером (`max-width: 100%`), текст обрезается многоточием
  (`.content` с `overflow: hidden`), кнопки не сжимаются — часть визуального контракта,
  покрыта stories `WithOverflow` и `VisualTests`.

## Accessibility

- Собственной ARIA-роли у тега нет: корневой `<span>` — контейнер. Роль группы задаёт `TagGroup`
  (`role="group"`).
- Кнопки — `ButtonIcon` без текстового контента, поэтому **доступное имя обязан задать
  потребитель**: `editButtonProps={{ "aria-label": "..." }}` и
  `removeButtonProps={{ "aria-label": "..." }}`. Без них кнопки остаются безымянными
  для скринридера. Компонент не подставляет умолчание намеренно — строки на конкретном языке
  внутри библиотеки запрещены.
- Клавиатура: собственных обработчиков у тега нет, работает нативная семантика `<button>`
  (Tab / Enter / Space). Порядок фокуса совпадает с порядком в DOM: сначала редактирование,
  затем удаление.
- Кольцо фокуса рисует `ButtonIcon` через `:focus-visible`, то есть только при переходе
  с клавиатуры.
- При `disabled` обе кнопки получают нативный `disabled` и выпадают из порядка фокуса,
  колбэки не вызываются.

## Связанные компоненты

- `TagGroup` — контейнер группы тегов (`role="group"`), задаёт раскладку и переносы;
  собственный `size` передаётся ему отдельно, теги внутри свой `size` получают сами.
- `TagColor` — визуально похожая плашка, но неинтерактивная: без кнопок, зато со `status`
  (`DEFAULT` / `SUCCESS` / `INFO` / `WARNING` / `ERROR`). Берётся, когда нужна метка состояния,
  а не снимаемое значение.
- `ButtonIcon` — рендерится внутри как кнопка редактирования и удаления; от него тег получает
  форму, состояние `disabled` и стили фокуса. Все props из `editButtonProps` / `removeButtonProps`
  уходят именно на него.
- `Text` — рендерит контент тега; тег выбирает `size` (`ETextSize`) и `type` (`EFontType`)
  по своим `size` и `disabled`.
