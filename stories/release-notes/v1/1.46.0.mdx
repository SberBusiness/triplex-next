<Title>v1.46.0</Title>

<Heading>Изменения</Heading>

**ChipMultiselect**

- Проведён AI-рефакторинг: изменений для потребителя нет.

**ChipSort**

- Проведён AI-рефакторинг: изменений для потребителя нет.

**ChipSuggest**

- Проведён AI-рефакторинг: `ChipSuggest` больше не оборачивает переданный `ref` в новую функцию на каждый рендер, поэтому стабильный callback-`ref` перестал переприкрепляться (элемент, на который указывает `ref`, прежний). Других изменений для потребителя нет.

**DateField**

- Проведён AI-рефакторинг, добавлен `displayName` у внутреннего управляющего элемента поля.

**HelpBox**

- Проведён AI-рефакторинг: `HelpBox` больше не оборачивает переданный `ref` в новую функцию на каждый рендер, поэтому стабильный callback-`ref` перестал переприкрепляться. Автогенерируемый `id` подсказки теперь имеет вид `HelpBox-<n>` вместо `:r<n>:`. Других изменений для потребителя нет.

**TextareaField**

- `height` заменен на `min-height`.
