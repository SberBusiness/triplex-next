# AmountField

## Назначение

Поле ввода денежной суммы. Пока пользователь печатает, значение форматируется на лету
(разряды разделяются пробелом, целая и дробная части — запятой: `1234.56` → `1 234,56`),
а наружу через `inputProps.onChange` уходит нормализованное значение с точкой и без
разделителей разрядов (`"1234.56"`) — его можно отправлять на бэкенд без дополнительной
обработки. Дробная часть всегда дописывается до `fractionDigits` знаков, а каретка
удерживается в осмысленной позиции при вводе, удалении и вставке.

Композиция над семейством `FormField`: `TextFieldBase` (→ `FormGroup` → `FormField`) +
`FormFieldInput`, плюс собственный слой со знаком валюты.

Используй когда: пользователь вводит сумму — платёж, лимит, ставку, любой денежный
показатель, который нужно показывать с разрядами и хранить числом.

Не используй когда: нужно только показать готовую сумму без ввода (`Amount`), нужен
счётчик/произвольное число без денежного форматирования (`NumberField`), значение имеет
фиксированный формат-маску (`MaskedField`) или формат произвольный (`TextField`).

## Варианты и props

`IAmountFieldProps` расширяет `ITextFieldBaseProps` (кроме `children`), поэтому
`size`, `status`, `active`, `label`, `prefix`, `postfix`, `description`, `counter`,
`className` и div-атрибуты ведут себя так же, как у `TextField`.

### Обязательные props

| Prop | Тип | Описание |
|---|---|---|
| `inputProps` | `Omit<IFormFieldInputProps, "type" \| "maxLength" \| "onChange" \| "inputMode" \| "autoComplete"> & { value, onChange, ref? }` | Свойства поля ввода. `value` — нормализованное значение (`"1234.56"`, пустая строка для пустого поля), `onChange(value)` получает такое же нормализованное значение, `ref` — ссылка на `<input>`. Остальные атрибуты (`placeholder`, `id`, `onFocus`, `onBlur`, `onKeyDown`, `onSelect`, data-атрибуты) пробрасываются в `FormFieldInput`. |

### Опциональные props

| Prop | Тип | По умолчанию | Описание |
|---|---|---|---|
| `size` | `EComponentSize` | `LG` | Размер поля: SM / MD / LG. Тот же размер получает слой со знаком валюты. |
| `status` | `EFormFieldStatus` | `DEFAULT` | Статус: default / error / warning / disabled. `DISABLED` блокирует input и приглушает знак валюты. |
| `currency` | `string` | — | Наименование валюты справа от значения. Не рендерится, пока отформатированное значение пустое. |
| `maxIntegerDigits` | `number` | `16` | Максимальное количество знаков перед запятой. Лишние цифры не попадают в значение. |
| `fractionDigits` | `number` | `2` | Количество знаков после запятой. `0` — поле без дробной части. |
| `onClear` | `() => void` | — | Обработчик очистки. Если передан, перед пользовательским `postfix` рендерится `FormFieldClear`. Компонент сам значение не сбрасывает — это делает потребитель. |

### Особенности поведения

- **Значение контролируемое и нормализованное.** В `value` хранится `"<целая>.<дробная>"`
  без разделителей разрядов; в поле показывается форматированный вариант с запятой.
  Значение, пришедшее снаружи, нормализуется только для отображения: `"1234,5"` покажется
  как `1 234,50`, но `onChange` при этом не вызывается — в состоянии потребителя останется
  `"1234,5"`, пока пользователь не отредактирует поле. Синхронизировать состояние с
  нормализованным видом компонент не берётся: это задача потребителя.
- **Дробная часть дополняется нулями** до `fractionDigits`. Ввод только дробной части
  (`,5`) восстанавливает целый ноль → `"0.50"`. Если целой части нет, а дробная нулевая
  (`,00`) — значение считается пустым (`""`).
- **Ведущие нули отбрасываются** вместе со всем, что стоит перед первой значащей цифрой;
  любые символы, кроме цифр и десятичного разделителя, игнорируются.
- **Разделители.** Ввод принимает и `,`, и `.` как десятичный разделитель. В отображаемом
  значении разряды разделяются обычным пробелом (U+0020), десятичная часть — запятой.
- **Placeholder.** Если `inputProps.placeholder` не передан (или пустая строка), он
  генерируется из `fractionDigits`: `0,00` при `2`, `0` при `0`.
- **Каретка.** После каждого ввода позиция каретки пересчитывается с учётом добавленных
  разделителей и восстанавливается в layout-эффекте. Если значение снаружи не изменилось
  (ввод невалиден или значение то же), каретка ставится хелпером `setFallbackCaret` —
  он же учитывает `Backspace`/`Delete` рядом с разделителем и направление выделения.
- **Знак валюты** рисуется поверх поля отдельным слоем: невидимая (`color: transparent`)
  копия значения задаёт отступ, за ней идёт сам `currency`. Копия помечена
  `aria-hidden="true"`.
- **`data-test-id`** на компоненте порождает суффиксы: `{id}__input` на элементе ввода и
  `{id}__unit` на знаке валюты.

Переопределяются через `ThemeProvider` (prop `tokens`) — см. `ThemeProvider-ai.md` →
«Как переопределять токены». Значения по умолчанию — `src/components/DesignTokens/components/FormField.ts`.

```text

```

Собственных токенов у `AmountField` нет: знак валюты красится теми же токенами, что и текст
поля, остальное оформление наследуется от семейства `FormField`.

## Инварианты

- `forwardRef` на компоненте — не убирать. Внешний `ref` указывает на корневой `<div>`
  `FormField`, ссылка на `<input>` передаётся через `inputProps.ref`.
- Публичный API (`IAmountFieldProps`: `inputProps`, `currency`, `maxIntegerDigits`,
  `fractionDigits`, `onClear` + унаследованные от `ITextFieldBaseProps`) — изменение имён,
  типов и дефолтов является breaking change.
- `inputProps` не принимает `type`, `maxLength`, `inputMode`, `autoComplete` и собственный
  `onChange` с сигнатурой события: их задаёт сам компонент (`inputMode="decimal"`,
  `autoComplete="off"`, `onChange(value: string)`).
- Формат нормализованного значения (точка как десятичный разделитель, отсутствие
  разделителей разрядов) — часть контракта: на нём построены потребители, отправляющие
  значение на бэкенд.
- Разделитель разрядов в отображаемом значении — обычный пробел U+0020, тогда как
  `Amount` (отображение суммы) использует `AmountConst.GroupSeparator` — неразрывный
  пробел U+00A0. Различие существующее и наблюдаемое (копирование значения, e2e-селекторы),
  менять его без отдельного решения нельзя.
- `AmountBaseInputCore`, `AmountBaseInputParser`, `AmountBaseInputFormatter` и `utils.ts` —
  внутренняя кухня компонента, из barrel `index.ts` не экспортируется.
- Экземпляр `AmountBaseInputCore` живёт в `useRef` весь срок жизни компонента: он хранит
  позицию каретки и кэш выделения между рендерами. Пересоздавать его на каждый рендер или
  заменять на state нельзя — потеряется каретка.
- CSS-класс `currencyLayout` используется в unit-тестах как селектор слоя валюты —
  переименование потребует правки теста.

## Accessibility

- Лейбл — настоящий `<label htmlFor>`: `FormFieldInput` генерирует `id` через `lodash uniqueId`
  и связывает его с `FormFieldLabel`. Свой `id` можно передать в `inputProps`.
- Копия значения под знаком валюты помечена `aria-hidden="true"` — скринридер читает только
  значение поля и сам знак валюты.
- `inputMode="decimal"` даёт числовую клавиатуру на мобильных устройствах.
- `status={EFormFieldStatus.DISABLED}` выставляет нативный `disabled` — поле штатно выпадает
  из таб-обхода.
- Семантика ошибки (`aria-invalid`, `aria-describedby`) не хардкодится: при необходимости
  потребитель передаёт атрибуты через `inputProps`.
- Кнопка очистки (`onClear`) — `FormFieldClear` без текста: `aria-label` задаёт потребитель
  там, где компонент используется, — библиотека мультиязычная.
- Собственных клавиатурных сокращений нет; `onKeyDown` и `onSelect` из `inputProps`
  вызываются после внутренних обработчиков, которые запоминают нажатую клавишу и выделение
  для расчёта каретки.

## Связанные компоненты

- `TextFieldBase` — базовая раскладка поля (`FormGroup`/`FormField` + слоты `prefix`,
  `label`, `postfix`, `description`, `counter`); `IAmountFieldProps` наследует её props.
  Живёт в семействе `TextField`.
- `FormField` / `FormFieldInput` — контейнер поля и сам элемент ввода, куда уходит
  `inputProps`.
- `FormFieldClear` — кнопка очистки, которую компонент добавляет в постфикс при `onClear`.
- `Amount` — отображение уже готовой суммы (без ввода), парная компонента для read-only
  сценариев.
- `NumberField` — поле для произвольных чисел без денежного форматирования.
- `MaskedField`, `TextField` — соседние поля той же группы `TextFields` для форматов с
  маской и произвольного текста.
