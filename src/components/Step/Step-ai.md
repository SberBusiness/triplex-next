# Step

## Назначение

Круглый индикатор одного шага: номер внутри кружка, цвет фона и цвет номера кодируют статус
(`DEFAULT` / `DONE` / `ACTIVE` / `ERROR` / `WARNING` / `DISABLED`). Компонент рисует ровно один
шаг — ряд шагов и связь между ними собирает потребитель. Если передан `children`, кружок
оборачивается в `Tooltip`, раскрывающийся по наведению.

Используй когда: нужно показать номер и состояние отдельного шага внутри своей вёрстки
пошагового сценария — так его использует `IslandAccordion` для нумерации секций.

Не используй когда:

- Нужен готовый горизонтальный степпер с переключением шагов, подписями и клавиатурной
  навигацией — возьми `Stepper` (или `StepperExtended` для произвольного состава шагов).
  `Step` в реализацию `Stepper` не входит: у того собственный `StepperStep`.
- Нужен кликабельный элемент. `Step` рендерит `<div>` без роли, фокуса и обработчиков —
  интерактивность придётся навешивать снаружи, вместе с ролью и клавиатурой.
- Нужно показать статус без номера — возьми `Marker` или `MarkerStatus`.

## Варианты и props

### Обязательные props

| Prop | Тип | Описание |
|---|---|---|
| `step` | `number` | Номер шага. Рендерится внутри кружка через `Text` (`B1`, semibold). Компонент не форматирует и не ограничивает значение: двузначные номера помещаются, кружок под содержимое не растягивается |
| `status` | `EStepStatus` | Состояние шага. Определяет **только** пару цветов — фон кружка и цвет номера |

### Опциональные props

| Prop | Тип | По умолчанию | Описание |
|---|---|---|---|
| `size` | `EComponentSize` | `EComponentSize.MD` | Размер кружка. SM и MD дают 28px, LG — 32px |
| `position` | `EStepPosition` | `EStepPosition.Default` | Позиция шага в ряду. Влияет **только** на выравнивание указателя подсказки и потому имеет смысл лишь вместе с `children` |
| `children` | `React.ReactNode` | — | Содержимое подсказки. Без него подсказка не создаётся и `Tooltip` не монтируется вовсе |

Остальные props — стандартные атрибуты `div`
(`IStepProps extends React.HTMLAttributes<HTMLDivElement>`), уходят на корневой элемент
через `...rest`.

### Размер и статус независимы

Две оси не пересекаются: `size` отвечает за геометрию, `status` — за пару цветов. Любая
комбинация допустима, поэтому матрицу 3×6 целиком покрывает story `VisualTests`,
а документационные stories показывают оси по отдельности.

### `position` и подсказка

`position` отображается на `alignTip` подсказки: `XFirst` → `START`, `Default` → `CENTER`,
`XLast` → `END`. Для крайних шагов ряда указатель прижимается к краю, чтобы подсказка
не выходила за границы ряда. Без `children` prop ни на что не влияет.

Значение для ряда шагов считает экспортируемый хелпер `calcPosition(stepCount, i)`:
`XFirst` для `i === 0`, `XLast` для последнего, иначе `Default`. Для ряда из одного шага
возвращает `XFirst` — проверка на первый шаг идёт первой.

## Дизайн-токены

Переопределяются через `ThemeProvider` (prop `tokens`) — см. `ThemeProvider-ai.md` →
«Как переопределять токены». Значения по умолчанию — `src/components/DesignTokens/components/Step.ts`.

```text
Step.Background_Default
Step.Background_Done
Step.Background_Active
Step.Background_Error
Step.Background_Warning
Step.Background_Disabled
Step.Color_Default
Step.Color_Done
Step.Color_Active
Step.Color_Error
Step.Color_Warning
Step.Color_Disabled
```

По паре токенов (`Background_*` + `Color_*`) на каждое значение `EStepStatus`; добавление
статуса означает и два новых токена. Цвет номера задаётся селектором `& > span` — он попадает
на элемент, который рендерит `Text`.

Размеры (28 / 32px, `border-radius: 50%`) заданы литералами в `styles/Step.module.less` — они
специфичны для компонента. Брейкпоинт адаптива берётся из LESS-переменной `@screen-sm-max`.

## Инварианты

- `forwardRef<HTMLDivElement>` — не убирать. Ref всегда указывает на корневой `<div class="step">`,
  и в варианте с подсказкой тоже: внешний ref мерджится с внутренним через
  `setForwardedRef` (`src/helpers/setForwardedRef.ts`).
- Внутренний ref на корневой `<div>` обязателен: он уходит в `Tooltip` как `targetRef` —
  относительно этого узла считается позиция подсказки. Убрать внутренний ref или перевесить
  его на другой элемент нельзя.
- Корневой элемент — `<div>`. Кружок центрует содержимое через `display: flex`; смена тега
  сломает вёрстку и типизацию props.
- `displayName` — `"Step"`. Не менять.
- Значения `EStepStatus` (`"default"` / `"done"` / `"active"` / `"error"` / `"warning"` /
  `"disabled"`) совпадают с именами CSS-классов в `Step.module.less` и с суффиксами токенов
  `Step.Background_*` / `Step.Color_*`. Переименование значения enum — ломающее изменение
  сразу в трёх местах.
- Значения `EStepPosition` — `PascalCase` (`Default` / `XFirst` / `XLast`), в отличие от
  остальных enum'ов библиотеки. Это часть публичного API, приводить к общему виду нельзя.
- Подсказка монтируется только при непустом `children`. Оборачивать кружок в `Tooltip`
  безусловно нельзя: пустая подсказка перехватывала бы наведение.
- `EStepStatus.DISABLED` — только цвет. Ни `pointer-events`, ни `aria-disabled` компонент
  не выставляет, подсказка у выключенного шага продолжает работать.
- Экспорты `Step`, `IStepProps`, `calcPosition`, `EStepStatus` и `EStepPosition` идут в barrel
  `src/components/Step/index.ts` — сохранять. `calcPosition` внутри компонента не используется,
  но входит в публичный API: он нужен потребителю, который собирает ряд шагов.
- `className` деструктурируется из props и мерджится через `clsx`, поэтому в `...rest`
  его нет и перезатереть базовые классы он не может.

## Accessibility

- Собственной ARIA-роли нет: корневой `<div>` — неинтерактивный контейнер, в порядок фокуса
  не попадает, обработчиков клавиатуры у компонента нет.
- Номер шага — единственное, что читает скринридер. Смысл шага в разметку не попадает:
  текст подсказки живёт в `Tooltip`, который раскрывается по наведению или клику мышью
  и с клавиатуры недоступен. Если шаг должен быть понятен без мыши, опиши его видимым
  текстом рядом в своей вёрстке.
- Статус кодируется только цветом. Дублируй его видимым текстом на стороне потребителя.
- Одного `aria-label` на `Step` недостаточно: корневой `<div>` без роли получает роль
  `generic`, которой [спецификация HTML-AAM](https://www.w3.org/TR/html-aria/) запрещает
  доступное имя, — атрибут попадёт в разметку через `...rest`, но скринридер его не
  озвучит. Если имя нужно именно на шаге, передай вместе с ним роль, допускающую
  именование: `<Step step={2} status={EStepStatus.ERROR} role="img" aria-label="Шаг 2, ошибка" />`.
- Ряд шагов семантики списка не создаёт: если нужна структура, оберни шаги в `<ol>`/`<li>`
  на стороне потребителя.
- Компонент не хардкодит текстовые строки: содержимое подсказки и любые `aria-label` задаёт
  потребитель. Библиотека мультиязычная.

## Связанные компоненты

- `Stepper` — готовый горизонтальный степпер с подписями, выбором шага и клавиатурной
  навигацией. Альтернатива, когда нужен весь сценарий целиком, а не отдельный индикатор.
  Общего кода со `Step` нет: у `Stepper` собственный `StepperStep`.
- `Tooltip` — рендерится вокруг кружка, когда передан `children`. `Step` фиксирует
  `size={ETooltipSize.SM}` и `toggleType="hover"`, а из props потребителя прокидывает
  только выравнивание указателя (`alignTip`) — остальное настроить нельзя. `disableAdaptiveMode`
  не передаётся, поэтому на экранах до `SM_MAX` включительно подсказка открывается
  в адаптивном (полноэкранном) режиме.
- `Text` — рендерит номер шага (`ETextSize.B1`, `EFontWeightText.SEMIBOLD`). Цвет номера
  задаётся снаружи, селектором `& > span` в стилях `Step`.
- `IslandAccordion` — потребитель: нумерует секции аккордеона, передавая `Step` номер,
  статус и `size`. Опирается на то, что `Step` рисует только кружок, без внешних отступов.
