<Title>v1.51.0</Title>

<Heading>Ломающие изменения</Heading>

**Carousel**

- Удалён enum `ECarouselOrientation`: используйте общий `EOrientation`, значения те же.
- Удалены токены `Carousel.Indicator_*`: индикаторы теперь красятся токенами `PageIndicators.Indicator_*` с теми же именами и значениями. Если вы переопределяли их через `ThemeProvider`, перенесите ключи в группу `PageIndicators`.

**ImageGallery**

- Свойство `showDots` переименовано в `showPageIndicators`, `dotsProps` — в `pageIndicatorsProps`, тип `TImageGalleryDotsProps` — в `TImageGalleryPageIndicatorsProps`.

**ImageGalleryExtended**

- Часть `ImageGalleryExtended.Dots` заменена на `ImageGalleryExtended.PageIndicators`, тип `IImageGalleryExtendedDotsProps` — на `IImageGalleryExtendedPageIndicatorsProps`. Замените `<ImageGalleryExtended.Dots />` на `<ImageGalleryExtended.PageIndicators />`.
- Изменено: вместо не более 4 тиков — индикатор на каждое изображение, видимо окно из 5. Ряд стал WAI-ARIA `tablist`: активный индикатор помечается `aria-selected="true"` вместо `aria-current`, стрелки, `Home` и `End` переключают изображение. Подписи индикаторов можно задать через `indicatorProps`.
- Изменено: отступ 16px между частями галереи теперь задаёт только лента миниатюр, индикаторы страниц прилегают к картинке вплотную. Своей разметке между частями задайте отступ самостоятельно.
- Удалены токены `ImageGallery.Dot_Background_*`: индикаторы красятся токенами `PageIndicators.Indicator_*`.

<Heading>Изменения</Heading>

**EmptyView**

- Проведён AI-рефакторинг.

**EOrientation**

- Добавлен общий enum ориентации `EOrientation` (`HORIZONTAL` / `VERTICAL`), его используют `Carousel` и `PageIndicators`.

**MonthYearRange**

- Проведён AI-рефакторинг.

**NotificationGrouped**

- Проведён AI-рефакторинг.

**NumberField**

- Добавлено: `NumberField` передаёт `ref` на корневой контейнер `FormField` (`HTMLDivElement`) и имеет `displayName="NumberField"`. Тип компонента изменился с `React.FC` на `React.ForwardRefExoticComponent`.
- Исправлено: каретка не смещается влево, когда при вводе удаляется символ правее неё. Например, при вводе цифры перед ведущим минусом каретка остаётся после введённой цифры.

**OrderedList**

- Изменено: внутренняя CSS-переменная начального номера переименована с `--start-index-tx` в `--triplex-next-runtime-OrderedList-Root_CounterReset` — она видна в inline-стиле корневого элемента.
- Проведён AI-рефакторинг: других изменений для потребителя нет.

**PageIndicators**

- Добавлен компонент `PageIndicators` — ряд индикаторов страниц с окном из 5 видимых индикаторов и навигацией с клавиатуры. Его используют `Carousel.Indicators` (без изменений для потребителя) и `ImageGalleryExtended.PageIndicators`.

**PaginationExtended**

- Проведён AI-рефакторинг.

**SMSField**

- Проведён AI-рефакторинг. `SMSField` и `SMSField.Submit` принимают `ref`: на корневой `div` и на `button` соответственно. Для ссылки на поле ввода по-прежнему передавайте `ref` в `SMSField.Input`.
- Исправлено: `onKeyDown` у `SMSField.Input` получал событие с `currentTarget` на обёртке поля, теперь — на `input`.
