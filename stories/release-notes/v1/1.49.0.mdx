<Title>v1.49.0</Title>

<Heading>Ломающие изменения</Heading>

**Divider**

- `IDividerProps` больше не принимает `children`: `<hr>` не может содержать потомков, и раньше такая передача падала в рантайме, теперь её отсекает TypeScript.

<Heading>Изменения</Heading>

**Button**

- Исправлен баг: иконка не перекрашивалась при наведении на кнопку, если курсор не находился ровно над иконкой или текстом (например, над паддингом кнопки).

**ButtonDropdownExtended**

- Добавлены горизонтальные отступы `12px` между соседними `ButtonDropdownExtended`, а также между `ButtonDropdownExtended` и `Button` в обоих порядках.

**Calendar**

- Исправлена стилизация: скругление ячеек в видах `MONTHS` и `YEARS` в обычном режиме совпадает с адаптивным.
- Изменён разделитель диапазона лет в заголовке — короткое тире (`–`) без пробелов вместо `" - "`.

**CardAction**

- Изменены токены `Card.Shadow_Default` и `Card.Shadow_Hover` в тёмной теме — вместо `none` используются `DarkShadow.03` / `DarkShadow.06`.

**Design Tokens**

- Добавлены группы дизайн-токенов `Shadow` и `DarkShadow` для использования как значения `box-shadow`.

**Divider**

- Добавлено: `Divider` пробрасывает `ref` на корневой `<hr>`. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Проведён AI-рефакторинг.

**DocumentNumberEdit**

- Добавлено: `DocumentNumberEdit` пробрасывает `ref` на корневой элемент — раньше компонент был объявлен как `React.FC`, поэтому переданный `ref` терялся. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Проведён AI-рефакторинг: других изменений для потребителя нет.

**Dropdown**

- Изменена прозрачность токена `Dropdown.Shadow` в тёмной теме — 0.25 вместо 0.35.

**Ellipsis**

- Изменено: внутренняя CSS-переменная числа строк переименована с `--ellipsis-line-clamp` в `--triplex-next-runtime-Ellipsis-Root_LineClamp` — она видна в inline-стиле корневого элемента.
- Исправлено: переданный в `Ellipsis` `style` больше не отменяет `maxLines` — раньше собственные стили потребителя затирали число строк, и текст обрезался по одной строке.
- Проведён AI-рефакторинг: других изменений для потребителя нет.

**FooterPage**

- Изменена прозрачность токена `FooterPage.StickyShadow` в светлой (0.15 вместо 0.08) и темной темах (0.5 вместо 0.35).

**HeaderPage**

- Изменена прозрачность токена `HeaderPage.StickyShadow`в светлой ( 0.15 вместо 0.08) и тёмной темах (0.5 вместо 0.35).

**Notification**

- Изменена прозрачность токена `Notification.Shadow` в тёмной теме — 0.25 вместо 0.35.

**SegmentedControl**

- Добавлено: `SegmentedControl.Segment` пробрасывает `ref` на свою `<button>` — раньше компонент был объявлен как `React.FC`, поэтому переданный `ref` терялся. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Проведён AI-рефакторинг: других изменений для потребителя нет — публичный API и внешний вид прежние.

**Skeleton**

- Добавлено: `Skeleton` пробрасывает `ref` на свой корневой `<div>` — раньше компонент был объявлен как `React.FC`, поэтому переданный `ref` терялся. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Проведён AI-рефакторинг, добавлен `displayName`: других изменений для потребителя нет.

**Spoiler**

- Проведён AI-рефакторинг: изменений для потребителя нет — публичный API и внешний вид прежние.

**Step**

- Добавлено: `Step` пробрасывает `ref` на корневой элемент (кружок шага) — раньше компонент был объявлен как `React.FC`, поэтому переданный `ref` терялся. Тип компонента изменился на `React.ForwardRefExoticComponent`.
- Проведён AI-рефакторинг: других изменений для потребителя нет.

**TextField**

- Добавлено: из пакета экспортируется тип `ITextFieldBaseProps` — базовые props текстовых полей. `TextField`, `MaskedField`, `AmountField` и `TextareaField` наследуют его без `children`; так же типизируются props собственной обёртки: `Omit<ITextFieldBaseProps, "children">`. Компонент `TextFieldBase` по-прежнему внутренний.
