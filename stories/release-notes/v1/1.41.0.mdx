<Title>v1.41.0</Title>

<Heading>Ломающие изменения</Heading>

**FormField**

- `statusToClassNameMap` больше не экспортируется — ни из `components/FormField`, ни из корня пакета. Маппинг статуса на CSS-класс переименован во внутреннюю константу `STATUS_TO_CLASS_NAME_MAP` и стал деталью реализации компонента. Воспроизвести его на стороне потребителя нельзя: имена классов хешируются при сборке вместе с версией библиотеки (`error` → `error__58eeaf1b`) и меняются от релиза к релизу. Визуальное состояние поля задаётся prop `status` у `FormField` — используйте его; если нужно опереться на состояние в собственных стилях, навешивайте свой класс рядом.

<Heading>Изменения</Heading>

**FormField**

- Исправлено: `className`, переданный в `FormFieldDescription` или `FormFieldCounter`, затирал базовый класс компонента вместо того, чтобы дополнять его. Теперь классы объединяются, как у остальных компонентов библиотеки.
- AI-рефакторинг: документация props и значений `EFormFieldStatus`, внутренние упрощения и расширенные unit-тесты. Охвачены `FormFieldInput`, `FormFieldLabel`, `FormFieldPrefix`, `FormFieldPostfix`, `FormFieldClear`, `FormFieldDescription`, `FormFieldCounter`. Остальной публичный API не изменён.

**IconWrapper**

- AI-рефакторинг: JSDoc на props, расширены unit-тесты. Публичный API и поведение не изменены.

**Island**

- Исправлено: `className`, переданный в `IslandHeader` (`Island.Header`) или `IslandFooter` (`Island.Footer`), затирал базовый класс компонента вместо того, чтобы дополнять его. Теперь классы объединяются, как в `IslandBody` и у остальных компонентов библиотеки. Это влияет на любой код, передающий `className` в эти части: базовый класс остаётся на элементе, поэтому к нему снова применяются отступы `Island` и `position: relative` из стилей части. Последнее меняет containing block — абсолютно спозиционированные потомки внутри такой части теперь позиционируются относительно неё, а не относительно ближайшего внешнего positioned-предка. В самой библиотеке это заметно на `IslandAccordion` — между телом и подвалом раскрытого элемента появился вертикальный отступ, заданный размером острова.
- AI-рефакторинг: JSDoc на props, значениях `EIslandType` и субкомпонентах, `displayName` у `IslandHeader`, `IslandBody`, `IslandFooter`, добавлены unit-тесты. Публичный API не изменён (props, значения enum, barrel-экспорты, `forwardRef` — как были).

**IslandAccordion**

- Между телом и подвалом раскрытого элемента появился вертикальный отступ, заданный размером острова (8/12/16px для SM/MD/LG) — следствие исправления мержа `className` в `Island.Footer`, см. **Island**.

**StatusTracker**

- Добавлены токены `StatusTracker.Background` и `StatusTracker.Draft_Color`.
- Токен `StatusTracker.Draft_Background` теперь задает цвет подсветки статуса `draft`.
- Изменены цвета токенов `StatusTracker.Draft_Background`, `StatusTracker.Draft_Color`, `StatusTracker.Rejected_Color` в светлой и темной темах.
- Минимальная высота изменена для десктоп экранов и удалена для мобильных экранов.

**Tooltip**

- Исправлено: подсказка, смонтированная сразу открытой (управляемый режим `isOpen`), не закрывалась по действию мышью вне неё — при монтировании навешивался обработчик `click`, а снимался `mousedown`.
- Исправлено: класс темы больше не снимается с контейнера, если в течение задержки закрытия подсказку открыли снова или контейнер занял другой `Tooltip`.
- Исправлено: в адаптивном (мобильном) режиме свойства `size` и `alignTip` больше не уходят в DOM — React больше не предупреждает о нераспознанном атрибуте `alignTip`.
- Исправлено: при размонтировании открытой подсказки с `toggleType="hover"`, а также при смене `toggleType` на лету обработчики наведения снимаются и навешиваются и на саму подсказку, а не только на целевой элемент.
- AI-рефакторинг: разбор `children` вынесен в чистую функцию и мемоизирован, значение контекста стабилизировано, дедуплицирована разметка `Tooltip.Link`, из расчёта координат убрано двойное приведение типов, в хуке темы вынесен хелпер и добавлен guard при размонтировании, `displayName` внутреннего `TooltipDesktopBase` приведён к имени класса, добавлены JSDoc на props и приватные методы, добавлены unit-тесты. Публичный API не изменён (props, значения enum, barrel-экспорты, `forwardRef` — как были).
