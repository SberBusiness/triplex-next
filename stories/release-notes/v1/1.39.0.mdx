<Heading>Ломающие изменения</Heading>

**Button**

- `ButtonBase` (и `IButtonBaseProps`) убран из barrel-экспорта `components/Button` — это внутренний базовый компонент. При необходимости импорт доступен по прямому пути `@sberbusiness/triplex-next/components/Button/ButtonBase`.

<Heading>Изменения</Heading>

**Button**

- Исправлено: строковое значение `aria-expanded="false"` ошибочно включало визуальное состояние «раскрыто» (класс `expanded` и активное состояние иконки). Раскрытым теперь считается только `true` / `"true"`.
- `size` стал опциональным со значением по умолчанию `EComponentSize.MD` — типы приведены в соответствие с реализацией.
- AI-рефакторинг: JSDoc на props и компоненте, unit-тесты расширены с 10 до 27 кейсов. Остальной публичный API не изменён.

**AlertContext**

- AI-рефакторинг: JSDoc на всех props, выбор иконки по умолчанию переведён на маппинг типов. Из стилей удалены избыточные `font-size` / `line-height` — типографику текста задаёт `Text`.

**ButtonDropdown**

- AI-рефакторинг: JSDoc на компоненте, dots- и обычный триггер объединены в один рендер с общей a11y-обвязкой, тема кнопки и палитра каретки выведены через маппинги вместо приведения типа и `switch`, добавлены unit-тесты. Сам рефакторинг поведение и разметку не менял; расширение API и поведенческие исправления — отдельные пункты ниже.
- Типы триггера и props-интерфейсы вариантов теперь экспортируются: `TButtonDropdownButtonTheme`, `TButtonDropdownTheme`, `IButtonDropdownBaseProps`, `IButtonDotsProps` (расширение API, поведение не изменилось).
- Исправлено: перехват `Space` на кнопке-триггере не срабатывал (обработчик сравнивал `event.key` с легаси-значениями) — теперь сравнение идёт по `event.code`, пробел явно открывает/закрывает dropdown с корректным `preventDefault`.
- Исправлено: `label` опции утекал в DOM как невалидный атрибут элемента выпадающего списка (для не-строковых `label` — с warning в консоли React).
- Новые props `opened` / `setOpened` — типизированный controlled-режим открытости dropdown (ранее `opened` работал только через нетипизированный spread во внутренний `ButtonDropdownExtended`).

**Calendar**

- AI-рефакторинг: JSDoc на props и внутренних компонентах, codestyle-чистка, unit-тесты (Calendar, CalendarViewItem, utils), создан `Calendar-ai.md`. Публичный API и наблюдаемое поведение не изменены; внутренний `CalendarFooter` теперь применяет объявленные, но ранее игнорировавшиеся `className` и `...rest`.
- Исправлено: для `pickType={ECalendarPickType.MONTH_YEAR}` внешняя смена `pickedDate` на другой месяц выставляла заголовок в формате «March 1970» вместо «1970» — до следующего перелистывания. Заголовок теперь всегда форматируется по текущему виду отображения.
- Исправлено: после смены страницы с клавиатуры (`PageUp` / `PageDown`) фокус не возвращался на новую tabbable-ячейку, если она занимала ту же позицию сетки (в видах месяцев и годов — всегда). Фокус восстанавливается только когда он уже находился внутри сетки — программная смена страницы фокус не забирает.
- Исправлено: выбор первой tabbable-ячейки страницы (когда `pickedDate` вне страницы, а начальные даты отключены) перебирал кандидатов с накоплением шага (0, +1, +3, +6…), а в виде годов прибавлял месяцы вместо лет — tabbable-ячейкой могла стать не первая доступная дата, либо она не назначалась вовсе.
- Расширение API: поля `dateFrom` / `dateTo` в `IDateLimitRange` стали опциональными — типы приведены к фактическому поведению: незаданная граница берётся из `globalLimitRange`. Внешнему TS-коду, читающему эти поля, может потребоваться проверка на `undefined`.
- Расширение API: функциональный вариант `dayHtmlAttributes` теперь допускает возврат `data-*` атрибутов (`TTdHTMLAttributesWithData`) — как и объектный вариант. Функции с явной аннотацией возврата старым типом `React.TdHTMLAttributes<…>` нужно перевести на `TTdHTMLAttributesWithData`.

**Col**

- Компонент `Col` переведён на использование `forwardRef` (ref ведёт на корневой `div`).
- AI-рефакторинг: JSDoc на всех props и экспортируемых типах. Публичный API не изменён.

**Page**

- Вертикальные внутренние отступы изменены: 24px (было 32px) для desktop и 8px (было 16px) для мобильных экранов. Горизонтальные отступы не изменились.

**LightBox / LightBoxSideOverlay**

- Удалены избыточные переопределения вертикальных отступов `Page` — отступы теперь задаются только стилями самого `Page` (визуальный результат не изменился).

**LightBox**

- Исправлено: клавиатурные триггеры контролов (`clickByArrowLeft` / `clickByArrowRight` у `Controls.Prev` / `Controls.Next`) не срабатывали на экранах шире 1024px, а Esc у `Controls.Close` — на экранах уже 1024px (триггер ссылался на скрытую кнопку другого режима).
- Исправлено: при размонтировании лайтбокса в течение 100мс после открытия скролл страницы мог остаться заблокированным (незачищенный таймер возвращал класс `bodyOverflowHidden`). Таймер-фикс заменён счётчиком открытых лайтбоксов, сценарий переключения между лайтбоксами через роутер сохранён.
- Исправлено: `LightBoxViewManager` не снимал с mount-ноды CSS-классы позиционирования (`LightBoxMountNodeViewManager`, `LB-*`) при размонтировании; классы удаляются при размонтировании последнего лайтбокса.
- AI-рефакторинг: JSDoc на всех props, общая реализация стрелок Prev/Next, общий хук видимости сайдбаров, unit-тесты. Публичный API не изменён; props-интерфейсы контролов и `SideOverlayLoader` теперь экспортируются.

**Row**

- Добавлен `forwardRef` — ref пробрасывается на корневой `div`.
- AI-рефакторинг: JSDoc на всех props и контексте, значение `RowContext` мемоизировано (предотвращает перерендеры колонок `Col` через контекст, пока `gridHorizontalGap` не меняется). Публичный API не изменён.

**Typography (Text / Title / Caption / CodeText)**

- AI-рефакторинг: JSDoc на всех props и значениях enum (подсказки в IDE), дублирующаяся логика классов `underline` / `strikethrough` вынесена во внутренний хелпер. Публичный API не изменён.
