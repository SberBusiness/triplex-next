<Title>v1.42.0</Title>

<Heading>Изменения</Heading>

**LoaderSmall**

- AI-рефакторинг: JSDoc на компоненте, props и значениях `ELoaderSmallTheme`, порядок импортов приведён к codestyle, константы-маппинги переименованы в `THEME_TO_CLASS_NAME_MAP` / `SIZE_TO_CLASS_NAME_MAP` (внутренние, не экспортировались), в стилях объединено дублирующееся объявление анимации точек — сама анимация задана один раз на `.dot`, у точек осталась только `animation-delay`, unit-тесты расширены с 3 до 6 кейсов, создан `LoaderSmall-ai.md`. Экспортируемый, но неиспользуемый компонентом enum `ELoaderSmallSize` сохранён и помечен в документации как legacy — размер задаётся `EComponentSize`. В stories `controls: { disable: true }` перенесён на верхний уровень `parameters` — внутри `docs` он не применялся. Публичный API и поведение не изменены (props, значения enum, barrel-экспорты, DOM-разметка, `role="status"`, токены — как были).

**MobileView**

- AI-рефакторинг: у `MobileView` появился `displayName`, у `useMobileView` — явный тип возвращаемого значения `boolean`, уточнён JSDoc компонента и хука. Добавлены unit-тесты (15 кейсов на компонент и хук) и stories по modern pattern, создан `MobileView-ai.md`. Публичный API и поведение не изменены: props `children` и `fallback`, сигнатура `useMobileView`, barrel-экспорты и граница мобильной ширины (`EScreenWidth.SM_MAX`, `max-width: 767px`) — как были.
