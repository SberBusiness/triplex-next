# CheckboxYGroup

## Назначение

Компонент-группа для компоновки чекбоксов с направлением по оси `Y`. Используется как контейнер для нескольких `Checkbox`, когда нужно разложить их вертикально.

Используй когда: несколько связанных чекбоксов нужно разместить вертикально.
Не используй когда: чекбоксы должны идти в строку — используй `CheckboxXGroup`.

---

## Варианты и props

### Обязательные props

Обязательных custom-props нет.

### Опциональные props

| Prop | Тип | По умолчанию | Описание |
|---|---|---|---|
| `children` | `React.ReactNode` | — | Внутри обычно рендерятся `Checkbox`. Компоненты, оборачивающие `Checkbox`, тоже допустимы, но обёртка вокруг каждого `Checkbox` разрывает соседство `label`-ов и вертикальный отступ пропадает — см. «Ограничения использования». |
| `...divAttributes` | `Omit<React.HTMLAttributes<HTMLDivElement>, "role">` | — | Стандартные HTML-атрибуты для корневого элемента, кроме `role`: роль всегда `group`. |

### Ограничения использования

- Корневой элемент — `<div role="group">`, разметка построена на `inline-flex` и `flex-flow: column wrap`.
- Вертикальный отступ задаётся правилами вида `.checkboxYGroup .label.md + .label.md` (потомковый + соседний комбинатор), поэтому его получают только соседние `label`-элементы `Checkbox` одного размера — на любой глубине вложенности внутри группы. Для произвольных children (текст, свой контрол, обёртка без `Checkbox` внутри) отступ не применится.
- Обёртка вокруг каждого `Checkbox` (`<Wrapper><Checkbox /></Wrapper>` × 2) разрывает соседство `label`-ов — отступ пропадает. Два `Checkbox` внутри одной общей обёртки отступ, наоборот, получат, хотя прямыми детьми группы не являются.
- На мобильном брейкпоинте величина внутреннего отступа одинакова для всех размеров, но правила те же — отступ по-прежнему применяется только между соседями одного размера.
- Там же (`@screen-sm-max`) группа дополнительно получает собственный внешний отступ `margin: 14px 16px` — на десктопе своих внешних отступов у неё нет.

## Дизайн-токены

Компонент не использует собственных CSS-переменных. Все визуальные стили наследуются от `Checkbox`.

---

## Инварианты

- `forwardRef` обязателен и должен указывать на корневой `<div>`.
- Корневой DOM-элемент компонента — `<div>`, роль зафиксирована как `role="group"`.

---

## Accessibility

- `role="group"` описывает группу взаимосвязанных контролов.
- Семантика чекбоксов остаётся нативной на уровне `Checkbox` внутри группы.

---

## Связанные компоненты

- `Checkbox` — базовый чекбокс, обычно используется внутри `CheckboxYGroup`.
- `CheckboxXGroup` — аналогичная группа, но с направлением по оси `X`.
