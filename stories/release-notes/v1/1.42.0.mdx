<Title>v1.42.0</Title>

<Heading>Изменения</Heading>

**AlertProcess**

- Исправлено: `className`, переданный в `AlertProcess.Spoiler`, полностью затирал собственные классы элемента — `{...rest}` расходился после `className`, поэтому вместе с пользовательским классом пропадали `expandableContent` / `expanded` и ломалась анимация раскрытия. Теперь класс мерджится через `clsx`, как в остальных компонентах.
- Исправлено: `AlertProcess.Spoiler` не пробрасывал `ref` — компонент был объявлен как `React.FC`. Теперь это `forwardRef`, ref указывает на элемент раскрываемого контента, то есть на тот же элемент, что получает `...rest`.
- AI-рефакторинг: JSDoc на всех props с указанием значений по умолчанию, в `IAlertProcessProps` добавлен явный `children`, `renderIcon` приведён к `||` вместо тернарника (как в `AlertContext`), убрано дублирующее присваивание `AlertProcess.Spoiler` после `Object.assign`, удалена ссылка на несуществующий CSS-класс `styles.spoiler` (в сборке она давала `undefined`, визуально ничего не меняется), из LESS удалено мёртвое правило `.alertTypeFeature .themeIcon { padding-top: 0 }`. Unit-тесты разбиты на `AlertProcess.test.tsx` и `AlertProcessSpoiler.test.tsx` и расширены с 11 до 34 кейсов, stories переведены на modern pattern, создан `AlertProcess-ai.md`. Публичный API не изменён (props, их типы, значения enum, barrel-экспорты — как были), визуальное отображение компонента не изменилось.
