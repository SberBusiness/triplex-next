# RadioYGroup

## Назначение

Вертикальный контейнер для связанных радио-кнопок с ролью `radiogroup` по умолчанию.
Компонент задаёт раскладку и семантику группы; выбор остаётся на уровне вложенных
`Radio` и приложения.

Используй когда: нужно разместить варианты одного выбора друг под другом.
Не используй когда: варианты должны идти в строку — используй `RadioXGroup`;
для независимых множественных вариантов подходит семейство `Checkbox`.

---

## Варианты и props

### Обязательные props

Обязательных props нет.

### Опциональные props

| Prop | Тип | По умолчанию | Описание |
|---|---|---|---|
| `children` | `React.ReactNode` | — | Обычно несколько `Radio` с общим `name` и разными `value` |
| `className` | `string` | — | Добавляется к классу корневого контейнера через `clsx` |
| `role` | `React.AriaRole` | `radiogroup` | Стандартный HTML-prop; позволяет переопределить роль |
| `aria-label` / `aria-labelledby` | HTML/ARIA-атрибуты | — | Доступное имя группы задаёт потребитель |
| `...divAttributes` | `React.HTMLAttributes<HTMLDivElement>` | — | Остальные атрибуты и обработчики событий корневого `<div>` |

### Ограничения использования

- Собственных `size`, `checked`, `defaultChecked`, `disabled`, `name` и `value`
  у группы нет: их передают каждому дочернему `Radio`. Группа не клонирует children
  и не передаёт им props через контекст.
- Одинаковый `name` связывает нативные радио-кнопки в один выбор. Независимым
  наборам в одной форме нужны разные `name`; сами контейнеры их не изолируют.
- В controlled-режиме приложение хранит выбранное значение, передаёт `checked`
  каждому `Radio` и обновляет значение через его `onChange`. В uncontrolled-режиме
  начальный выбор задаётся `defaultChecked` одного `Radio`.
- Раскладка корня — `display: inline-flex` и `flex-flow: column wrap`. Ширина
  и внешние отступы не задаются.
- Смежные `Radio` одного размера получают вертикальный отступ: SM — 8px,
  MD — 16px, LG — 20px. Правила `.label.sm + .label.sm`, `.label.md + .label.md`
  и `.label.lg + .label.lg` из `styles/RadioYGroup.module.less` используют общие
  классы семейства `Radio`: `scripts/generate-scoped-name.ts` формирует имя класса
  из семейства, локального имени и версии библиотеки. Между соседями разных размеров
  и между произвольными children эти отступы не назначаются; отдельная обёртка
  вокруг каждого `Radio` разрывает соседство `label`-элементов.
- `aria-disabled` на контейнере не отключает дочерние контролы: для блокировки
  взаимодействия нужен `disabled` у каждого `Radio`.

## Дизайн-токены

Собственных дизайн-токенов у `RadioYGroup` нет: его LESS задаёт только раскладку.
Цвета, hover, focus и disabled вложенных радио-кнопок используют токены группы
`Radio` из `src/components/DesignTokens/components/Radio.ts`; их переопределяют
через `ThemeProvider` по общим правилам темизации.

## Инварианты

- `forwardRef<HTMLDivElement>` обязателен; объектный и callback ref указывают
  на корневой `<div>`, а при размонтировании callback получает `null`.
- `className`, `ref` и HTML-атрибуты относятся к одному корневому `<div>`.
- Роль по умолчанию — `radiogroup`; `{...rest}` идёт после роли, поэтому переданный
  `role` её переопределяет. Не фиксировать роль и не исключать `role` из интерфейса
  без согласования изменения публичного поведения.
- `RadioYGroup` и `IRadioYGroupProps` экспортируются через
  `src/components/Radio/index.ts`; `displayName` — `RadioYGroup`.
- Селекторы отступов связаны с классами `label`, `sm`, `md`, `lg` из
  `Radio.module.less` через общий генератор имён в Vite и Storybook. Учитывать эту
  связь при изменении классов, расположения модулей или генератора.
- Компонент не хранит выбор, не управляет фокусом и не перехватывает клавиатуру.
- Story IDs `components-radioygroup--*` связаны с visual baselines;
  legacy IDs из `stories/Radio.stories.tsx` также сохраняются.

## Accessibility

- `role="radiogroup"` описывает набор вариантов одного выбора. Потребитель
  передаёт `aria-label` либо `aria-labelledby`, ссылающийся на существующую
  подпись группы. Текст внутри компонента не задаётся.
- Каждый `Radio` остаётся нативным `<input type="radio">` внутри `<label>`;
  его children задают подпись конкретного варианта. Для варианта без текста
  потребитель должен передать доступное имя самому `Radio`.
- Клавиатура и выбор работают через нативные radio inputs с общим `name`.
  Контейнер не реализует отдельную стрелочную навигацию и не переносит фокус.
- Корневой `<div>` по умолчанию не фокусируется. `ref` не вызывает фокусировку;
  потребитель может передать `tabIndex`, если сценарий требует фокуса контейнера.
- Disabled и `:focus-visible` отображаются на дочернем `Radio`.

## Связанные компоненты

- `Radio` — базовый элемент семейства; задаёт размер, значение, выбор,
  disabled и обработчики отдельных вариантов.
- `RadioXGroup` — альтернативная горизонтальная раскладка с собственным `indent`.
